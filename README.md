- Project file: `avariika.uproject`
- Runtime module: `Source/Avaryo`
- Main content root: `Content/Avariika`
- Startup maps: `/Game/Avariika/Maps/MainMenu/L_MainMenu` (game) and `/Game/Avariika/Maps/Lvl_FirstPerson` (editor).
- Engine association: UE 5.8.

Close Unreal Editor before a full C++ build when Live Coding may interfere:

```powershell
"C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\Build.bat" avariikaEditor Win64 Development -project="C:\unrealEngine\avariika_UE58_sandbox\avariika.uproject" -WaitMutex
```
