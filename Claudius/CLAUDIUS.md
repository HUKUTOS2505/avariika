## How to Call Commands

Write JSON into `Plugins/Claudius/claudius_request.json` (single-file mode) or POST to `http://127.0.0.1:8765/api/v1/commands`:

```json
{
  "id": "my_call",
  "category": "level",
  "command": "list_all_actors",
  "parameters": {"max_results": 10}
}
```

Responses land in `claudius_response.json` (single-file) or as the HTTP body.

## Curation System (NEW in v3.0)

Only commands in the ENABLED INDEX below are fully documented. The FULL INDEX further down lists every command in the plugin along with an enabled flag. If you need a command that is currently disabled, use `config.enable_command` (ask the user first unless they have set `auto_enable_policy` to `always`). This keeps context cheap without hiding what's possible.
