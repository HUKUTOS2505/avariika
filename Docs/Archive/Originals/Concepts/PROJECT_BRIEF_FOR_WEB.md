# «Авариика» — бриф проекта (для составления плана)

> Документ самодостаточный: всё нужное здесь, доступа к репозиторию у тебя нет.
> Нужно: помочь составить план дальнейшей разработки 1-го этажа дома и игрового цикла.

## 1. Что за игра
Кооперативный **хоррор-комедия** про бригаду аварийной службы (сантехника/электрика/газ).
Игроки приезжают по заявке в дом, **устраняют аварии** (прорыв воды, утечка газа, обрыв
проводки, неисправные двери), борются со **шкалой паники** и бытовыми «угрозами», получают
оплату и уезжают. Тон: серьёзная авария + бытовой абсурд. Кооп до 4 игроков.

Базовый игровой цикл (готов и PIE-проверен): **заявка (доска в хабе) → приехать → починить
аварии (вода/газ/электрика/двери) → выход (ExitZone) → оплата**. Есть шкалы здоровья, паники,
«туалета», система перетаскивания (drag) сбитого напарника, рация.

## 2. Технологии
- **Unreal Engine 5.7.4**, рендер Lumen, апскейл TSR (база).
- Игровой **C++ модуль `Avaryo`** (основная логика на C++, контент/настройка — в Blueprint поверх).
- Сетевой кооп: OnlineSubsystem (сейчас **Null** для локальных тестов) + плагин **EOSCore** (Epic Online Services) для будущего онлайна. Ключи EOS в `DefaultEngine.ini`.
- Целевое железо разработчика: ~8 ГБ VRAM сейчас (план апгрейда на RTX 4080S/5080) — перф держать умеренным.
- Платформа разработки: Windows 11, редактор UE открыт; правки C++ — Live Coding (тело функций) или Build.bat (новые члены/полная пересборка).

## 3. C++ классы (Source/Avaryo)
**Персонаж/компоненты:**
- `AAvaryoCharacter` — игрок, true-FPS шаблон UE5.4 (FP-камера на кости head). Здоровье/урон, инвентарь, взаимодействие (E), фонарик, drag напарника, монтажи реакций (сейчас ОТКЛЮЧЕНЫ для чистой локомоции).
- `UVitalsComponent` — здоровье, паника, «туалет»; события OnWounded/OnRevived. (Сейчас Health/Panic = 50/50 для тестов; **перед релизом вернуть 100/0**.)
- `UFlashlightComponent` — фонарик.

**Мир / интерактив:**
- `ARepairable` — база аварий. Подтипы по данным: `Repairable_WaterPipe` (💧 прорыв воды), `Repairable_GasPipe` (🔥 утечка газа). Чинится инструментом.
- `APowerSwitch` — рубильник/электрощит; `bLiveWireWhenBroken` (живой провод бьёт током при разливе воды).
- `ADoor` — дверь (открытие E), может быть заперта/сломана.
- `AExitZone` — зона выхода (завершение заявки).
- `ACallBoard` — доска заявок в хабе (выбор задания «Дом» → грузит карту `L_Dom`).
- `AToilet`, `AFoamPatch` (пена/разлив), `AFloodlight`, `AToolCase` (ящик инструментов), `ATrap`.
- `ABioPickup`/`ABioProjectile`/`APickupItem` — предметы/пикапы. Инвентарь: «1 тяжёлый предмет на земле + 4 слота».

**Game/UI:**
- `ARunState` — состояние забега (заявка, прогресс, оплата).
- `AvaryoPlayerController`, `MenuGameMode`/`MenuHUD`, `AvaryoHUD`, `DispatchSubsystem` (диспетчер заявок), `CompanyLedgerSubsystem` (бухгалтерия/деньги), `AvariikaOnlineSubsystem`, `AvariikaSaveGame`, `AvaryoCameraShakes`.

## 4. Карты

## 5. Ассеты и персонажи
- **Скелет/анимации:** почти все анимации на скелете маннекена (UE4 Mannequin). NPC-бригада на `CitizenNPC` (UE4-mann, compatible skeleton) — анимации UE4 идут напрямую. ~196 анимов оператора отретаргечены. Модульная одежда через CitizenNPC. Голова/руки персонажа чинятся в C++ BeginPlay (Leader Pose).
- Звуковая база для «монстра-слухача» готова, **но самого монстра НЕ делать без явной отмашки**.
- **Дом строится из 2 паков:** `ResidentialHouses` (основа, `/Game/ResidentialHouses/...`, модульные стены/полы/потолки/лестницы/двери + мебель) и `AtmosphericHouse` (подвал + props). Высоты этажей: 1–2 эт = 3 м, чердак 2.2–2.4 м, подвал 2.2 м.
- **ВАЖНО про лицензии:** паки в основном пиратские = ПЛЕЙСХОЛДЕРЫ. До релиза: один лицензионный пак на категорию + свои meshy.ai-ассеты + докупить лицензии. НЕ «менять модель для обхода».
- 3D-модели делает пользователь в **meshy.ai** по промптам; анимации тоже пользователь.

## 6. Дом L_Dom — текущее состояние стройки (1 этаж)
Метод: модульно ПО ЧЕРТЕЖАМ (есть детальный план-чертёж 1 этажа), снап-сетка 100 см, высота этажа 3 м.
Дом **Г-ОБРАЗНЫЙ**: ЮЗ-угол (под гаражом) — двор/улица, ВНЕ дома.

**Раскладка (X запад→восток 0–14 м, Y юг→север 0–11 м, вход — юг по центру):**
- ГАРАЖ 28 м² — СЗ-угол X[0,4] Y[5,11]; ворота на запад. (💧⚡, в гараже вход в подвал по чертежу.)
- КУХНЯ 14 м² X[4,7] Y[7.5,11] (💧🔥); САНУЗЕЛ 6 м² X[4,7] Y[5.5,7.5] (💧); КЛАДОВАЯ 7 м² X[4,7] Y[3,5.5].
- ЛЕСТНИЦА 12 м² X[7,10] Y[3,7.5] (наверх; под ней — дверь в подвал); КОРИДОР X[7,10] Y[7.5,11]; ХОЛЛ/вход X[4,10] Y[0,3].
- ГОСТИНАЯ 28 м² X[10,14] Y[0,7.5] (⚡, камин); СТОЛОВАЯ 20 м² X[10,14] Y[7.5,11].
- ДВОР (вне дома) X[0,4] Y[0,5].

**Сделано:** пол (134 тайла, вырез двора), периметр Г-формы (вход юг, гаражный проём запад), внутренние перегородки на 7 комнат с дверными проёмами — все комнаты достижимы от входа. Уровень сохранён.

**Осталось по 1 этажу:** лестница (меш) + проём/дверь в подвал под ней, потолки, двери `ADoor` на проёмах, мебель/декор по комнатам, точки аварий (по 1 шт 💧🔥⚡ + двери) с привязкой к C++-системам, свет (Lumen, хоррор-сетап), PIE-самотест прохода.

**Этажи 2/3/чердак/подвал — отдельные фазы позже.**

## 7. Жёсткие правила (НЕ нарушать)
- Монстра-слухача НЕ делать без явной отмашки пользователя.
- Перед релизом вернуть Health=100, Panic=0 (сейчас 50/50 для тестов).
- Фиолетовый цвет в UI запрещён, акцент — **оранжевый**.
- Паки = плейсхолдеры, до релиза заменить/лицензировать; не «обходить» сменой модели.
- Работа по модулям: один модуль до конца (код+сборка+смоук+размещение+доки+пуш), потом следующий.
- Сборка/правки уровня — при определённом состоянии редактора (есть свои нюансы инструментов).
