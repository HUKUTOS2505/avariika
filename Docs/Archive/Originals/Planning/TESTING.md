# Чек-лист ручной проверки (ночные сессии 2026-06-11)

## ⭐ АУДИТ-ФИКСЫ 2026-06-22 (3 прохода: CODE_AUDIT / _2 / _3) — как проверить

> 38 фиксов за 3 аудита. Ниже — **соло-проверяемые** (как ты тестишь) и пометка кооп-онли (нужно 2 игрока: Net Mode=Listen Server, Players=2).
> Дев-команды — в секции ниже. Все собраны (Build Succeeded) и прошли смоук; геймплейная проверка — за тобой.

### Соло-проверяемо (важное, player-facing)
- [ ] **Огонь не добивает лежачего (AUDIT3 #1, gameplay-критично):** урони себя у газ-трубы (`AvVital health 0` рядом, потом взорви газ — закури в облаке) → загораешься раненым. Должно: **окно подъёма (40с) НЕ сгорает мгновенно** — тиммейт успевает поднять; раньше первый тик огня вырубал в «отруб». Любой повторный урон на раненом (ток/ловушка/снаряд) тоже больше не добивает мгновенно.
- [ ] **Бесконечный огнетушитель (AUDIT3 #2):** возьми огнетушитель с зарядом −1 (бесконечный, дефолт), дунь ЛКМ → **пшикает и НЕ глохнет на 1-м кадре** (раньше сразу обнулялся в пустой). Финитный баллон по-прежнему опустошается до 0 и замолкает.
- [ ] **Сигарету можно потушить в покое (AUDIT3 #3):** закури (Calm-предмет), дай панике упасть ≤1 (покурив), у газ-трубы снова нажми use → **сигарета тушится** (раньше при низкой панике use не срабатывал → форс-взрыв).
- [ ] **Газ-варнинг по выросшему облаку (AUDIT3 #4):** не перекрывай трубу, облако растёт; отойди на 2-4 м (внутри выросшего облака, но дальше старта) → статус **«ПАХНЕТ ГАЗОМ — НЕ КУРИТЬ!» теперь показывается** во всём облаке (раньше только в стартовом радиусе → курил «без предупреждения» и рвало).
- [ ] **E хватает то, на что смотришь (AUDIT2 #5 / Track1):** встань так, чтобы рядом были и фикстура (доска/ящик/рубильник/дверь), и другой объект (лут/ремонт). Смотри на нужный → **E берёт именно его**, фикстура сбоку больше не ворует приоритет. Порог `InteractFacingDot` (дефолт 0.5) тюнится в Details пешки.
- [ ] **Дебаунс двери/щитка (AUDIT2 #11):** спамь E по двери/рубильнику → **нет строба света / ре-электрификации воды / спама звука** (мин. интервал 0.4с).
- [ ] **Адреналин не отменяет спотыкание (AUDIT3 #10):** `AvVital health 20` (адреналин), разбегись и споткнись → **на спотыкании ход проседает до TripSlowSpeed** (адреналин больше не разгоняет сквозь стаггер).
- [ ] **Ранение роняет тяжёлое в мини-игре/туалете (AUDIT2 #10):** сядь в туалет/мини-игру с тяжёлым (сварочник), получи ранение → **тяжёлое падает** (раньше early-return оставлял в руках).
- [ ] **Каст обрывается при отрубе (AUDIT2 #8):** начни каст предмета, получи отруб → **каст не завершается hands-free**.
- [ ] **«Воняет» снимается визитом в туалет (AUDIT2 #1):** `AvVital smell 100` → статус «Воняет»; сходи в биотуалет до конца → **амбре спадает, «Испачкан» снят** (раньше висел вечно).
- [ ] **Санинцидент не копится в хабе (AUDIT2 #2):** стой в зоне ГАЗели (safe-zone) с полным пузырём → инцидент **НЕ срабатывает** в хабе.
- [ ] **Нет дюпа оплаты (AUDIT2 #3/#4):** ре-чини перегружающийся щиток несколько раз / спамь grab-release на раненом → **оплата за РАЗНЫЕ объекты/раненых раз, без фарма** (TSet-дедуп, сброс на старте забега).

## Дев-команды в консоль (тильда `~` в PIE, тестируй как ХОСТ/standalone)
Чтобы не ждать шкалы — выставляй состояние мгновенно (0..100):
- `AvVital panic 100` — паника (проверить шейк, панические крики, рост туалета).
- `AvVital bladder 100` или `AvIncident` — мгновенный санитарный инцидент (роняет биоснаряд, скачок паники/запаха).
- `AvVital smell 100` — мгновенно «воняет» (амбре тиммейтам, статус, реплика диспетчера).
- `AvVital health 5` — почти ранен; `AvVital health 0` фактически уронит на ближайшем уроне.
- `AvVital stamina 0` — выдохся.
- `AvGiveBio` — сразу дать «подозрительный комок» в руки (тест метания, руки пропахнут).
- `AvCheapGear` — форс дешёвого комплекта (моргающий фонарь + частые помехи рации) без перезапуска.
- `AvFinish win` / `AvFinish lose` — мгновенно завершить забег и показать «Акт» (проверить номер смены, кассу конторы, репутацию, звания, [R] следующая смена).

## НОВОЕ — Батч 2: хаос/хоррор (2026-06-13)
- [ ] **Пена-падение:** разгонись по своей пене — иногда не просто несёт, а роняет (стан). На пене капает паника.
- [ ] **Лежачий:** урони товарища (`AvVital health 0` у напарника) и пробеги по нему на бегу — споткнёшься.
- [ ] **Усталость:** `AvVital stamina 0` и беги — спотыкаешься заметно чаще.
- [ ] **Разброс броска:** `AvVital panic 100`, метни (T) — летит вкривь; спокойным — точно.
- [ ] **Кашель:** `AvVital smell 100` — периодически кашляешь (в логе MakeNoise, капля паники).
- [ ] **Удар по ноге:** толкни товарища со сварочником / поймай взрыв — иногда роняет сварочник + чуть урона себе.
- [ ] **Скрипы:** постой на смене — раз в ~30 с диспетчер «слышу скрип... показалось?».
- [ ] **Газ растёт:** не перекрывай трубу — облако ширится (дальше травит/громче рванёт); перекрыл — опало.
- [ ] **Тряска прицела:** на панике камера слегка дрожит (у себя).
- [ ] **HUD «Шум»:** беги/распыляй — полоска шума высокая; присядь и стой — низкая.
- [ ] **Адреналин:** `AvVital health 20` (не падая) — бежишь чуть быстрее, паника подрастает.
- [ ] **Несомого роняешь:** тащишь раненого, тебя толкнули/рвануло — выпустил его.

## НОВОЕ — Споткнуться (§18, 2026-06-13)
- [ ] Бегай (Shift) долго при выключенном фонаре — иногда спотыкаешься: ход резко проседает на ~0.8 с, слышен грохот.
- [ ] С включённым фонарём на бегу спотыкаешься заметно реже (темнота повышает шанс).
- [ ] При высокой панике (`AvVital panic 100`) на бегу спотыкаешься чаще.
- [ ] Раненый (ползком) и шагом — не спотыкаешься (только бег по земле).
- [ ] На клиенте проседание скорости видно сразу (без рывка-коррекции) — `bStumbling` реплицируется.

## НОВОЕ — Толчок / пинок (§18, 2026-06-13)
- [ ] Нажми **Q**, глядя на товарища в упор — его отбрасывает вперёд+вверх, ему капает паника.
- [ ] Толкни товарища в облако газа у пробитой трубы / на свою лужу пены (он поедет) / с края/лестницы — кооп-хаос работает.
- [ ] Толчок в пустоту (никого перед тобой) — просто кряхтение (шум), никого не задело.
- [ ] Есть перезарядка (~1.2 с) — нельзя спамить Q очередью.
- [ ] Толкать нельзя, пока сам ранен или сидишь в мини-игре.
- [ ] На клиенте: толкнул хоста/другого клиента — отлёт виден у всех (не только у толкающего).

## НОВОЕ — Скользкая пена (§18, 2026-06-13)
- [ ] Возьми огнетушитель, распыляй (ЛКМ) на пол — под струёй остаются белые лужи-диски.
- [ ] Пройди/пробеги по своей луже — теряешь сцепление, тебя проносит (тормозишь не сразу, заносит на поворотах).
- [ ] Сошёл с пены — сцепление возвращается, ходьба обычная.
- [ ] Тиммейт пробегает по твоей луже — его тоже проносит (проверить на клиенте, не только на хосте: скольжение должно совпадать).
- [ ] Лужи сами высыхают (исчезают) примерно через 25 с.
- [ ] Пустой баллон луж не делает; пена не блокирует проход (сквозь диск ходишь свободно).

## НОВОЕ — Биологический снаряд (§15, 2026-06-12)
- [ ] Доведи туалетную шкалу до санитарного инцидента — у ног появляется «Подозрительный комок» (маленькая сфера).
- [ ] Подбери его (E) — сразу скачок «Амбре» (испачкал руки), предмет в лёгком слоте «Подозрительный комок (1)».
- [ ] Подсказка «[ЛКМ] Метнуть комок (осторожно — зацепишь своих!)». ЛКМ — комок летит по направлению взгляда физикой, заряд кончается, предмет пропал.
- [ ] Попади в тиммейта — у него резкий скачок «Амбре» и паники; диспетчер язвит с именем жертвы.
- [ ] Кинь в стену/пол мимо — «шлёп» на месте падения: рядом стоящие ловят панику/запах; пару секунд держится «амбре-зона» (запах растёт у того, кто стоит в ней), в логе периодический MakeNoise; диспетчер про промах.
- [ ] Комок можно передать тиммейту по ПКМ (как любой предмет) — он испачкается при получении.

## НОВОЕ — Запах / Амбре (§16-17, 2026-06-12)
- [ ] Слева под витальными полосками появилась шкала «Амбре».
- [ ] Покури (сигареты) или постой в газовом облаке у трубы / попшикай огнетушителем — «Амбре» растёт; перестал — медленно спадает само.
- [ ] Доведи туалетную шкалу до санитарного инцидента — «Амбре» скакнуло вверх и держится (испачкан сам не выветривается).
- [ ] Когда «Амбре» выше середины — справа статус «Воняет», и диспетчер один раз язвит про запах.
- [ ] Встань вплотную к вонючему тиммейту (в ~3.5 м) — у стоящего рядом растёт паника (амбре подташнивает); отойди — перестаёт.
- [ ] В «Акте» у провонявшего колонка «вонял: N с» и возможное звание «Амбре смены». Денежного штрафа за запах нет.

## НОВОЕ — Предметы-ловушки / растяжка (§18, 2026-06-12)
- [ ] На платформе спавна лежит «Растяжка (2)» — подбери (E), встанет в лёгкий слот.
- [ ] Держа растяжку, подсказка «[ЛКМ] Поставить растяжку (взведётся через пару секунд!)». ЛКМ ставит ловушку у ног впереди, заряд −1.
- [ ] Ловушка пару секунд «спит», потом начинает мигать оранжевым (взвелась).

- [ ] В логе на срабатывание есть MakeNoise (задел под монстра-слухача).

## НОВОЕ — Не тот инструмент / колхоз (§18, 2026-06-12)
- [ ] Подойди к щитку БЕЗ тестера в руках (или с любым другим предметом) — подсказка теперь «[E] Чинить «Щиток» на коленке (без инструмента — рискованно)», а не «нужен инструмент».
- [ ] Зажми E без инструмента — идёт обычный бар «Колхоз: Щиток NN% (без инструмента)», НЕ мини-игра с курсором. Прогресс ползёт медленнее обычного.
- [ ] Во время колхоза периодически «косяк»: прогресс откатывается, чуть бьёт по HP, скачок паники, громкий звук (в логе MakeNoise).
- [ ] Колхоз можно прервать отпусканием E (как обычный ремонт), прогресс сохраняется; уйти за радиус — срывается.
- [ ] То же на генераторе без сварочника — колхозится held-E (без стартер-мини-игры).
- [ ] С ПРАВИЛЬНЫМ инструментом (тестер/сварочник) объект чинится по-старому мини-игрой — колхоз не активируется.
- [ ] Доведи колхоз до 100% — объект починен, диспетчер язвит про «художественную самодеятельность/народные методы».

## НОВОЕ — Репутация и касса конторы (§19, 2026-06-12)

- [ ] Числа в строках монтёров (итог ±₽) совпадают по знаку/масштабу с «Итогом смены» (формула общая).

## НОВОЕ — «Косяки оборудования» (2026-06-12)
- [ ] **Дешёвый комплект**: перезапусти PIE несколько раз — примерно в 40% забегов через ~6 с после приветствия диспетчер добавляет реплику про уценённое оборудование («фонари с рынка, рация с помехами…»). В остальных забегах её нет.

- [ ] Выключил рацию (тумблер) — помехи прекращаются; включил снова — отсчёт идёт заново.
