# LOCALIZATION — RU/EN (текущее состояние + как расширять)

> 2026-06-23. Цель: «язык» в настройках реально переключает текст. Реальность: почти весь UI — хардкод `TEXT("…")` на русском (FString, не FText), поэтому сделан прагматичный RU/EN-слой под Canvas-HUD.

## Как устроено — ДВА механизма (идёт миграция T → S)
В коде сосуществуют два хелпера из `Source/Avaryo/Public/AvariikaLoc.h`:

1. **`FAvLoc::S(Key)`** — ✅ ОСНОВНОЙ путь (на 13 языков). Тянет строку из **String Table «AvariikaUI»** по ключу; источник строк — `Content/Avariika/Localization/AvariikaUI.csv` (русский), переводы — через `.locres`-конвейер. Возвращает перевод текущей культуры либо русский фоллбэк.
   ```cpp
   DrawText(FAvLoc::S(TEXT("ui_002")), ...);   // "Продолжить" / "Resume" / … по культуре
   ```
2. **`FAvLoc::T(Ru, En)`** — 🟡 ЛЕГАСИ (только ru/en, инлайн). Возвращает EN если язык английский, иначе RU. Остаётся в нескольких местах вне HUD; постепенно вытесняется `S`.

Переключение языка — по `FInternationalization` текущей культуре (её ставит EasyOptionsMenu / `AvLang`). String Table регистрируется в рантайме (`AvariikaStringTable.cpp`, `LOCTABLE_FROMFILE_GAME`, отложенный хелпер на EndOfEngineInit).

## Что УЖЕ локализовано
**Через String Table `FAvLoc::S` (переводится на все 13 культур):**
- **Главное меню** (`MenuHUD`): заголовок, подзаголовок, кнопки (Создать/Найти/Настройки/Выход), экран поиска игр, подсказки. Ключи `menu_*`.
- **Пауза-меню + весь постоянный игровой HUD** (`AvaryoHUD`): ключи `ui_001…ui_077` (77 строк, см. ниже). Реально переведён `ru` (источник) + `en` (залит); 11 прочих культур — фоллбэк на ru до перевода.

Полный список локализованного «хрома» HUD (`AvaryoHUD::DrawHUD`):
  - Шкалы: Здоровье/Выносливость/Паника/Туалет/Амбре/Шум/Фонарь/Газоанализатор (+«ГАЗ — ОПАСНО!»).
  - Статусы (правый список): Ранен/Без сознания/Курит/Паникует/Устал/Несёт тяжёлое/Тащит/Промок/ГОРИТ!/Воняет/«НЕ КУРИТЬ!» и т.д.
  - Предупреждения: «ГЛАЗА! Нужна маска» (arc-eye), зарядка броска, «Всё починено — к ГАЗели».
  - Баннер ранения + обратный отсчёт bleed-out; монитор бригады (КАМЕРЫ/UNCONSCIOUS/BLEEDING OUT/(вы)).
  - Шапка задач (ЗАДАЧИ/TASKS), инвентарь (Тяж/Нет/Пусто/ВКЛ).
  - Инструкции мини-игр (вентиль/стартер/щиток/туалет/подготовка — «[E] жми в зелёной…»), подсказки удержания предмета ([ЛКМ]/[ПКМ] распылять/рация/растяжка/бросок/прожектор/передать), подсказки ящика/туалета/драга.
  - Магазин снаряжения (`DrawShop`, AvShop): названия инструментов + ур./МАКС/касса.

## Как проверить
Дев-команда: **`AvLang en`** → текст меню/паузы на английском; **`AvLang ru`** → обратно. (`AvLang` = `AAvaryoCharacter`, exec.)
Дропдаун языка в EasyOptionsMenu теперь показывает **Русский / English** (движковый таргет настроен, см. ниже) — выбор переключает культуру движка, на которой сидит и FAvLoc.

## Движковый таргет локализации (.locres) — ✅ НАСТРОЕН (2026-06-23)
Заведён стандартный localization target **Game** — это оживляет родной дропдаун EOM и кладёт фундамент под перевод FText-слоя (DisplayName/«Акт»/UMG).
- **13 культур** (Steam-матрица): `ru, en, fr, it, de, es, ja, ko, pl, pt-BR, zh-Hans, es-419, zh-Hant`. Проверено: `get_localized_cultures()` возвращает все 13, дропдаун покажет родные имена (русский/English/français/Deutsch/日本語/한국어/中文（简体）…).
- ⚠️ **Реально переведён пока только нативный `ru`.** Английский «хром» меню/HUD даёт **FAvLoc** (он знает только ru/en). Все 12 НЕ-нативных культур по FText-слою (DisplayName/«Акт»/EOM) пусты → фоллбэк на русский. То есть фундамент/список готов, **перевод — отдельная работа** (см. ниже про FText-миграцию хрома и заполнение архивов).
- **`Config/Localization/Game.ini`** — конфиг гэйзера: `NativeCulture=ru`, `CulturesToGenerate=` все 13; собирает из `Source/*` (LOCTEXT/NSLOCTEXT) и `Content/Avariika/*` (FText в ассетах/BP).
- **`Config/DefaultGame.ini`** — `[/Script/UnrealEd.ProjectPackagingSettings] +CulturesToStage=` все 13 (попадут в собранный билд).
- 🔑 **С 13 языками подход FAvLoc (инлайн ru/en) исчерпан** — нельзя вписать 13 строк в код. Поэтому хром меню/HUD переведён на **String Table** (CSV-ассет, удобный переводчикам) — строки попадают в архивы всех культур и переводятся вместе с DisplayName/«Актом». ✅ **Меню + весь постоянный HUD уже мигрированы** (`FAvLoc::S`, ключи `menu_*` + `ui_001…077`). Осталось на этот же конвейер: DisplayName-контент, «Акт», реплики диспетчера, EOM.
- **Сгенерено:** `Content/Localization/Game/{Game.manifest, Game.locmeta, ru/Game.{archive,locres}, en/Game.{archive,locres}}`. Трекаются в git (мелкие, source-of-truth перевода); генерёжные `*.csv/*_Conflicts.txt/*.po` — в gitignore.
- **Проверено в редакторе** (`InternationalizationLibrary`): `get_localized_cultures() == ["en","ru"]`, имена `русский`/`английский`, `set_current_language('en'/'ru')` переключает корректно.
- **Перегенерировать после изменений текста** (редактор ЗАКРЫТЬ):
  ```
  UnrealEditor-Cmd.exe avariika.uproject -run=GatherText -config="Config/Localization/Game.ini" -unattended -nopause
  ```
- **Чтобы реально ПЕРЕВЕСТИ FText** (DisplayName предметов/починок, «Акт», тексты EOM): заполнить английские строки в `Content/Localization/Game/en/Game.archive` (вручную или через **Localization Dashboard** в редакторе), затем перегенерить (команда выше скомпилит `.locres`). До перевода EN-игрок видит англ. «хром» (FAvLoc) + русские DisplayName (фоллбэк на нативную `ru`).
- ⚠️ Был осиротевший мусор `OGMainMenu` (en+de-DE .po от удалённого пака) в gitignore-папке — вычищен; таргет чистый ru/en.

## String Table «AvariikaUI» — конвейер (✅ меню + HUD, 2026-06-23)
Источник правды русских строк UI — **`Content/Avariika/Localization/AvariikaUI.csv`** (`Key,SourceString`). Регистрация — `Source/Avaryo/Private/AvariikaStringTable.cpp` (`LOCTABLE_FROMFILE_GAME("AvariikaUI", …, "Avariika/Localization/AvariikaUI.csv")`, отложенный хелпер). В коде: `FAvLoc::S(TEXT("ключ"))`.
- **Менять ТЕКСТ строки** (без новых ключей) — правишь только CSV, ребилд НЕ нужен (таблица читается из CSV в рантайме). Перевод подхватится после перегенерации `.locres`.
- **Добавить/переименовать КЛЮЧ** — нужен ребилд (на ключ ссылается код `FAvLoc::S`).
- **Перевод на культуры** — через стандартный gather→archive→locres.

**Скрипты миграции/перевода (`Scripts/`):**
- `migrate_loc.py` — массовая миграция `FAvLoc::T(ru,en)` → `FAvLoc::S(key)` в `.cpp`: извлекает пары из кода, присваивает стабильные `ui_NNN` (dedupe по ru), переписывает `.cpp`, дописывает ключи+ru в CSV, пишет EN-карту в `Scripts/loc_en.json`. (Один проход на файл; одноразовый.)
- `fill_loc.py` — заливает EN-переводы из `loc_en.json` в `en/Game.archive`.

**Полный цикл после изменения UI-строк (редактор ЗАКРЫТЬ):**
1. (если новые ключи) `Build.bat avariikaEditor …` — пересобрать код.
2. `UnrealEditor-Cmd.exe avariika.uproject -run=GatherText -config="Config/Localization/Game.ini" -unattended -nopause` — затянуть ключи в архивы всех 13 культур.
3. `python Scripts/fill_loc.py` — залить EN в `en/Game.archive`.
4. GatherText ещё раз (та же команда) — скомпилить `.locres` с переводами (gather сохраняет уже залитые переводы, не затирает).

## Как добавить перевод новой строки
Предпочтительно — **String Table**: добавь `ключ,русский_текст` в `AvariikaUI.csv`, в коде `FAvLoc::S(TEXT("ключ"))` (нужен `#include "AvariikaLoc.h"`), EN — в `Scripts/loc_en.json`, прогони цикл выше. Формат с числом — конкатенацией (UE5.7 `FString::Printf` не берёт рантайм-формат): `FAvLoc::S(TEXT("ui_game_prefix")) + FString::FromInt(n)`.
Легаси-вариант (только ru/en, без перевода на 13) — `FAvLoc::T(TEXT("рус"), TEXT("eng"))`; новый текст так больше не добавляем.

## ⚠️ Главный блокер полной игровой локализации: DisplayName — это КОНТЕНТ, а не код
Подсказки взаимодействия интерполируют имена объектов/предметов — `ARepairable::DisplayName`, `APickupItem::DisplayName` (это `FText` в дата-ассетах/блюпринтах, заданы по-русски). FAvLoc их НЕ переводит. Поэтому такие строки оставлены **целиком по-русски** (полу-перевод «Pick up Сварочник» хуже цельного RU):
- `[E] Поднять <DisplayName>`, `[E] Взять заявку: <Title>`, все подсказки починки (`Чинить/Дочинить/Закрутить вентиль/Заводить <DisplayName>`, «нужен инструмент: …»), метки прогресса мини-игр (`Вентиль/Стартер/Ремонт: <DisplayName> %`), «Применение: <DisplayName>».
- **Чтобы их перевести — нужен FText-путь**: перевести сами поля DisplayName/Title (NSLOCTEXT в C++ defaults или локализация дата-таблиц/BP) + .locres. Тогда код-обёртки («Поднять»/«Чинить») тоже стоит перенести на FText заодно.

## Ещё НЕ локализовано (большие батчи — на потом)
- **«Акт выполненных работ»** (финальный отчёт): звания («Барыга смены», «Электрик Эдисон», «Пожарный наоборот»…), сводка-заголовки, строки статистики. Это комедийный голос игры — **перевод требует творческой адаптации тона, лучше с юзером**, не вслепую. Виден раз за забег (низкий приоритет).
- **Реплики диспетчера** (`ARunState` namespace DispatcherLines — ~35 пулов флавора) — данные/флавор, тоже под FText или творческий проход.
- **EasyOptionsMenu** (UMG — там FText; его собственные тексты локализуются через его String Tables/.locres).
- **Подсказки с DisplayName** (см. блокер выше).

## Путь на ПОЛНУЮ локализацию (если масштаб/много языков)
Мигрировать на нативный UE: `NSLOCTEXT`/String Tables (FText) → Localization Dashboard → gather (`-run=GatherText`) → перевод → compile `.locres` → supported cultures в `DefaultGame.ini`. Тогда EasyOptionsMenu-дропдаун подхватит языки сам, и UMG локализуется. FAvLoc — временный мост для Canvas-HUD, при миграции заменяется на FText.
