## 1. ОКРУЖЕНИЕ (карты) — главный пробел

По WORKLOG: greybox забракован, решено строить на Fab-ассетах. Тебе нужны **4 локации** из концепта:

| Локация | Что нужно | Источник |
|---|---|---|
| 🏠 Жилой дом | подъезд, квартиры, подвал, лифт, щиток | Fab: `apartment` / `soviet apartment` |
| 🏭 Заброшенный завод | цеха, генераторы, трубы | Fab: `industrial factory` (мелькал в канале) |
| 🏥 Старая больница | палаты, морг, коридоры | City MODULAR HOSPITAL v.2 (выбран) |
| 🚢 Корабль | трюм, насосы, узкие коридоры | Fab: `ship interior` / `submarine` |

**Приоритет:** сделай ОДНУ локацию хорошо (больницу — ассеты уже выбраны), остальные потом. На старте по концепту (0.1) вообще нужен «маленький подвал/техпомещение».

💡 **Идея:** не делай 4 локации сразу. Сделай больницу как флагман, отполируй, выпусти. Остальные локации — контент-апдейты после релиза (даёт повод вернуться в игру + маркетинг «новая локация»).

**Обновление по каталогу `RawAssets/общее` (2026-06-13):** появились НЕ-больничные локации:
- 🏭 **Construction Pit** (2.1 ГБ, UE 4.17) — индустриальная стройплощадка + готовое ремонтное ядро (генератор/трубы/кабели/щитки). Лучшее соотношение польза/размер. Нужна миграция с 4.17.
- 🏠/🅿️ **AmericanDrive** (8.4 ГБ, UE 5.5) — экстерьер/дорога/гараж/жилой дом + готовый электрощит под мини-игру. Нативный 5.5 (без миграции).
- **Решение нужно:** под первый слайс берём ОДНУ (Construction Pit — если фокус «генератор/труба/щиток в цеху»; AmericanDrive — если «электрощиток на современном экстерьере/в доме»).
- **Всё ещё НЕТ:** интерьер корабля, интерьер цеха завода (только уличная стройка), модель рабочего, модель монстра, реалистичный меш трупа, **VFX (газ/искры/огонь/пена) — ноль**.

## 2. ПЕРСОНАЖИ — нужны модели людей

| Что | Детали | Источник |
|---|---|---|
| Модель монтёра | видна в коопе + на нагрудных камерах оператора | Meshy (T-pose) → авториг, ИЛИ Fab `worker character` |
| Вариации внешности | чтобы игроки различались (6 человек) | разные текстуры/шапки одной модели |
| Анимации движения | ходьба, бег, присед, прыжок, нести тяжёлое, тащить раненого, ползти (ранен) | Mixamo (бесплатно) + библиотека Meshy |
| Анимации действий | курить, чинить, тушить, толкнуть | простые, или held-use без анимации для прототипа |

**КРИТИЧНО:** генерь персонажей в Meshy в **T-pose/A-pose** (не «Ничто»!) — иначе авториг ляжет криво.

💡 **Идея — рабочая спецодежда даёт идентичность:** монтёры в оранжевых жилетах/касках. Это (а) тематично, (б) решает различение игроков (разный цвет каски = разный игрок), (в) каска — это лор для «экипировки» из концепта. Дёшево и узнаваемо.

## 3. МОНСТРЫ — модели + ИИ

По концепту монстра на старте 3, но монстр-слухач в коде ОТЛОЖЕН (вся шумовая база готова).

| Монстр | Модель | ИИ | Статус |
|---|---|---|---|
| Слепой слухач | Meshy (T-pose) или Fab creature | реакция на звук (база ✅), навигация, атака | ⬜ |
| Подражатель голосов | модель | копирует фразы из рации игроков | ⬜ позже |
| Хранитель | модель | сторожит предмет/комнату | ⬜ позже |

**На старт нужен ТОЛЬКО слухач** (концепт 0.1). Остальные — потом.

💡 **Идея по слухачу:** раз он слепой и идёт на звук — сделай его **визуально «слепым»** (нет глаз, большие уши/мембраны, голова-локатор). Игроки сразу читают механику по виду: «у него нет глаз → он не видит → надо тихо». Дизайн объясняет правила без туториала.

💡 **Идея — звук монстра важнее модели:** для слухача самое страшное не как он выглядит, а как звучит (дыхание, щёлканье, шаги). Вложись в его аудио больше чем в модель. Игроки чаще СЛЫШАТ его, чем видят.

## 4. ЗВУК — критично для хоррора (всё бесплатно)

Твоя игра вся построена на звуке (монстр-слухач, рация, шумомер). Звук = половина игры.

| Категория | Что | Источник |
|---|---|---|
| Шаги | по бетону/кафелю/металлу/воде | Freesound |
| Инструменты | сварка, дрель, вентиль, гудение генератора | Freesound |
| Окружение | дождь, капли, гул ламп, ветер, скрипы | Freesound / Pixabay |
| Рация | помехи, щелчки, шипение | Freesound |
| Монстр | дыхание, шаги, рык, щёлканье | Freesound + обработка |
| Реакции игрока | кашель, тяжёлое дыхание, «ой», крики паники | Freesound, или запиши сам |
| Взрыв/хаос | взрыв газа, искры, огнетушитель | Freesound |
| Туалет/комедия | звуки санинцидента (комедийные) | Freesound |
| Голос диспетчера | все реплики из концепта | **ElevenLabs** (ИИ) или сам + Audacity |
| Голоса монтёров | паник-крики, реплики | ElevenLabs / сам / друзья |
| Музыка | эмбиент-напряжение, тема меню, победа/провал | Pixabay Music, Incompetech (CC) |

💡 **Идея — диспетчер через ИИ-голос:** у тебя десятки реплик диспетчера (матерящийся, язвительный). Запиши их через ElevenLabs одним голосом — будет звучать как настоящий персонаж. Дёшево, быстро, и реплики легко добавлять.

💡 **Идея — голосовой чат уже работает на монстра:** если в коопе есть voice chat, монстр-слухач может реагировать на РЕАЛЬНЫЙ голос игроков (громко орёшь в микрофон → монстр слышит). Это гениально ложится на твою концепцию и есть в Lethal Company. Проверь, можно ли завязать MakeNoise на громкость микрофона.

## 10. МАГАЗИН И ПРОГРЕССИЯ СНАРЯЖЕНИЯ 💡 (реиграбельность)

Превращает ₽ из «Акта» в реальную прогрессию: заработал → купил снаряжение → берёшь сложные/дорогие заявки. Почти бесплатно в реализации — экономика (`ComputePlayerBalance`, `UCompanyLedgerSubsystem`) уже написана; не хватает только персиста на диск (`USaveGame`) и траты баланса.

| Что | Статус | Примечание |
|---|---|---|
| Экономика (доход/штрафы «Акта») | ✅ есть | `ComputePlayerBalance`, `ShiftNet` |
| Баланс/смена/репутация конторы | ✅ есть | `UCompanyLedgerSubsystem` (но не пишется на диск) |
| Персист прогрессии на диск | ✅ | `UAvariikaSaveGame` + леджер Load/Save + TrySpend (Фаза 1 готова) |
| Магазин (актор + UI в Hilux) | ⬜ | C++-экран, оранжевый акцент |
| Апгрейды инструментов (уровень, не новая модель) | ⬜ | `FEquipmentLevels` |
| Расходники (постоянный сток денег) | ⬜ | батарейки/предохранители/аптечки/бензин |
| Общий бюджет бригады | ✅ основа есть | `CompanyBalance` уже общий |
| Тиры заявок (дом→завод→корабль) | ⬜ позже | кусок крупнее магазина |

**Приоритет: ПОСЛЕ играбельного слайса + кооп-смоук-теста** (магазин — слой реиграбельности, не ядро). Полная спека: **`SPEC_Shop_Progression.md`**.

💡 Решения: общий бюджет (кооп-спор «копим на генератор?»), сейв хоста, апгрейд = уровень предмета, расходники = живой сток денег, сложность растёт со снаряжением (апгрейды открывают дорогие заявки, а не делают старт легче).

## ГЛАВНЫЕ ИДЕИ-УСИЛИТЕЛИ (резюме)

1. 💡 **Одна локация-флагман** (больница), остальные — апдейты после релиза
2. 💡 **Голосовой чат → монстр слышит реальный голос** (как Lethal Company, ложится на концепт идеально)
3. 💡 **Звук монстра важнее его модели** (он слепой — игроки его слышат)
4. 💡 **Слепой монстр выглядит слепым** (нет глаз, уши-локаторы — дизайн учит правилам)
5. 💡 **Каски разного цвета** = различение игроков + лор экипировки
6. 💡 **Экран «Акта» — это вирусный маркетинг** (сделай шарящимся)
7. 💡 **Диспетчер одним ИИ-голосом** (ElevenLabs) = живой персонаж дёшево
8. 💡 **Запаховый след монстра** (из твоего же концепта) — недооценённая крутая механика
