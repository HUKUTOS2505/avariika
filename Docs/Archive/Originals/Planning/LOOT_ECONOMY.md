# LOOT_ECONOMY — «тащи → вынеси → продай → апгрейдь»

> Дизайн-механика (2026-06-22, идея юзера). Аварийная бригада попутно тащит ценное из дома → продаёт → качает снарягу.
> Делает большой дом живым: каждая комната = «а вдруг тут что ценное» (решает мёртвые комнаты + награда за исследование).

## Цикл
**Найти лут в доме → донести до ГАЗели (вынести) → при выезде продаётся → деньги в кассу → между сменами апгрейды.**
Ключевое: лут **обналичивается ТОЛЬКО при победе** (выехал). Помер/не вынес — лут пропал. → жадность vs безопасность.

## Тиры лута (поле `APickupItem::SellValue`, ₽)
| Тир | SellValue | Слот | Примеры |
|---|---|---|---|
| Мелочь | 100–400 | лёгкий | нал, украшения, телефон, ручной инструмент |
| Средне | 500–1200 | лёгкий | электроника, антиквариат, моток меди/провода |
| Жирно | 1500–4000 | **тяжёлый (руки заняты)** | телек, сейф, мотор, ящик барахла |

Любой `APickupItem` с `SellValue > 0` = лут. Размещает дизайнер по комнатам (рандом-спавн для реиграбельности — позже).

## Соль = риск/награда
- Тащишь лут → слот/руки заняты → не починишь/не потушишь.
- Обыск = время → авария растёт (газ ширится, паника).
- **Ранили → роняешь** (механика уже есть из аудита).
- Тяжёлый лут (сейф/телек) = джекпот, но руки заняты весь забег → не работник.
- Кооп: делёжка, можно стащить из чужих рук — комедия предательства.

## Баланс — «не перегрузить»
- **Лут ВТОРИЧЕН.** Главное — починка (1500/шт) + выезд. Лут — рискованный бонус, не замена работе.
- Цены лута калибровать так, чтобы чистый забег-с-починкой ≈ забег-с-лутом-но-меньше-починок (выбор стиля, не доминирование).
- Плотность: ~1 лут-точка на 2–3 комнаты (см. [[ROOMS_PLAN]] — награда за исследование, не свалка).

## Фаза 2 (на потом, не в MVP)
- **Репутация-штраф за наглый грабёж:** тащить «личные/дорогие» вещи клиента → диспетчер злится → `ReputationPoints−` → хуже комплект/жёстче квота. Мораль + тормоз жадности (система репутации уже есть).
- **Скупщик/чёрный рынок:** отдельная точка сдачи в хабе (актор `ASellPoint`) для мгновенной продажи в середине цикла (сейчас — авто-продажа на выезде).
- **Личная доля vs касса:** делёжка между игроками (сейчас всё в общую кассу конторы).
- **Спец-лут под квест-цепочки.**
