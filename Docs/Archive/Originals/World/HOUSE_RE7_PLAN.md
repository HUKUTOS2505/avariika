# HOUSE_RE7_PLAN — дом по структуре RE7 (Бейкеры) под «Аварийку»

> Референс — **структура**, не ассеты. Геометрию из RE7 НЕ тащим (см. память `asset-licensing`).
> Строим на наших паках: `ResidentialHouses` (каркас) + `AtmosphericHouse` (подвал, worn-свапер, лестницы).
> Стройку геометрии делает ПОЛЬЗОВАТЕЛЬ (division-of-labor). Этот док — план, по которому строить.
> Аварии/двери/механики (`Repairable_*`, `APowerSwitch`, `ADoor`) — пак-независимы, их вешает Claude.

## Почему дом Бейкеров «идеален» — 5 приёмов (переносим ВСЕ)

1. **Вертикальный стек** 1 этаж → подвал → 2 этаж → тесный чердак. Контраст «просторно ↔ давит».
2. **Петли вместо коридоров** — наверх одним путём, вниз другим; короткие пути открываются по ходу (backtracking без скуки).
3. **Хаб safe-room** — у Бейкеров комната-сейв с сундуком. У нас = **холл с ящиком инструментов** (ToolCase), точка сбора бригады.
4. **Двери-гейты** — RE7 гейтит ключами-эмблемами; мы гейтим **починкой** (заварил трубу / снял рубильник / починил проводку → проход открылся).
5. **Темно и тесно** — фонарь обязателен; подвал и чердак особенно. Свет дома — на рубильнике (`PoweredLight`): размен «светло, но под током ↔ темно, но безопасно».

## Высоты этажей (просвет пол→потолок, UU; 1м = 100)

- **1 этаж: 300** — жилое, просторно
- **2 этаж: 300**
- **Чердак: 220–240** — низкий, давит
- **Подвал: 220** — клаустрофобия НАРОЧНО (хоррор)

Floor-to-floor = просвет + толщина перекрытия.

## Раскладка по уровням

### 1 ЭТАЖ — хаб и быстрые аварии (берём начатый Г-образный L_Dom за основу)
- **ХОЛЛ / главный вход** = safe-room-хаб: `ToolCase` (ящик инструментов), доска вызовов `ACallBoard`, старт бригады. Из холла видно лестницу наверх (как у Бейкеров — главный холл с парадной лестницей).
- **КУХНЯ** 💧🔥 — газовая авария (плита/труба), вода (мойка). Узел «перекрой газ перед заваркой».
- **ГОСТИНАЯ** ⚡ — главный щиток `SM_ElectricBox` + рубильник `APowerSwitch`, камин.
- **ГАРАЖ** — генератор + **вход в подвал** (люк/дверь под/у лестницы), ворота.
- **САНУЗЕЛ / КЛАДОВАЯ** — мелкие аварии, лут, проходные.
- Петля: вошёл → лестница впереди, налево бытовые комнаты, направо гостиная (уже совпало с правкой юзера в L_Dom).

### ПОДВАЛ — главный кластер аварий, темнота (из AtmosphericHouse)
- Высота 220, давит. Вход из гаража/из-под лестницы (заглушка-проём уже в плане Фазы A).
- **Кластер**: потоп 💧 (`Repairable_WaterPipe` + разлив) + **живой провод** ⚡ (бьёт током, сапоги НЕ спасают) + газовый котёл 🔥. Связка: обесточь рубильником → можно лезть в воду чинить, но темно.
- Ассеты: `AtmosphericHouse` `SM_Basement_stairs_*`, basement walls/ceiling, `Basement_props` (24 шт. — прямо под хоррор). worn-свапер на стенах = гниль.
- Фонарь обязателен. Свет подвала — на `PoweredLight` (рубильник).

### 2 ЭТАЖ — спальни/ванная, вода «сверху вниз»
- Высота 300. Петля назад в холл (вторая лестница / тот же пролёт).
- **Прорыв трубы** 💧 в ванной/спальне — визуально течёт, по легенде капает на 1 этаж (драма «чини быстрее»).
- Электрика 2-го этажа (проводка). Worn-свапер — обои отходят.
- Лестницы — `AtmosphericHouse` `SM_Stairs_straight_L_steps` (подъём ~3м, модульно; НЕ Residential — те великоваты, см. память `house-staircase-meshes`).

### ЧЕРДАК — тесный финальный узел
- Высота 220–240, узкий лаз (как гнилой чердак Бейкеров). Вход — лестница/люк со 2 этажа.
- Старая проводка (живой провод), осиное-гнездо-вайб, балки давят.
- Награда / ключевой этап смены (по необходимости геймдизайна).

## Порядок стройки (для пользователя)

1. **Подвал + 1 этаж (вертикальный слайс)** — сперва он, как договаривались (метод 🅱️-1: строишь по зонам, раз в этаж скрин для сверки).
2. Лестница 1↔подвал (проём под парадной лестницей), лестница 1↔2.
3. 2 этаж по периметру 1-го (несущие стены совпадают).
4. Чердак — поверх 2-го, со скосами/низким потолком.
5. Перекрытия с правильным просветом (см. высоты).
6. Двери `ADoor` на проёмы-гейты (список ниже).
7. Свет: лампы с тегом `PoweredLight` по этажам (рубильник рулит).

## Чек-лист дверей-гейтов (где починка открывает путь)

- [ ] Подвал: дверь/люк из гаража — открыт всегда, но за ним темно (рубильник) + вода (обесточь).
- [ ] Гостиная ⇄ остальное: щиток здесь, рубильник — «нервный узел» (свет vs ток).
- [ ] 2 этаж: ванная с прорывом — проход дальше после заварки трубы.
- [ ] Чердак: люк со 2 этажа — финальный гейт.

## Что НЕ ассетировано (нужен плейсхолдер / meshy)

- Газовый котёл (нет ни в одном паке) — meshy-плейсхолдер.
- Гаражные ворота из пака ≈8м не лезут в 3м проём (отложено в Фазе A — масштаб/замена).
