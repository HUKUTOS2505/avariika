# FACTORY_PACK_AUDIT — паки завода: что переиспользовать, что хранить

> Автономный аудит 2026-06-21 (read-only скан диска, ничего не удалял/не двигал).
> ⚠️ **Решение об удалении — за юзером.** По памяти `three-maps-plan` Завод и Больница — это **карты**,
> их паки НЕ мусор. Сверяться ПЕРЕД удалением любого пака (`asset-deletion-method`).
> Этот док — карта переиспользования + рекомендации, НЕ команда на удаление.

---

## TL;DR

- **Два фабричных пака: `IndustrialFactory` (21.2 ГБ) + `Warehouse` (16 ГБ) = 37 ГБ.** `AbandonedFactory` уже не на диске.
- Оба нужны **в первую очередь для карты «Завод»**, но в них **25–35% контента переиспользуется и для дома-хоррора**:
  трубы, кабели, щитки, котлы, газ-баллоны, ржавчина, мусор, инструмент, декали протечек/грязи, Niagara пар/огонь/искры.
- **Не нужно тащить весь пак в дом** — cherry-pick по списку ниже. Это снимает риск VRAM (8 ГБ) и захламления.
- **`Warehouse` ценнее для ДЕКЕЯ дома** (фотоскан-ржавчина, `PatchedWall`, мох, лужи, 47 ламп, крысы-Niagara),
  **`IndustrialFactory` — для механики-инфраструктуры** (5 вариантов щитков, котлы, газ-баллоны, водобаки).

## 3. Пересечение паков (для решения «оба или один»)

**Дублируют друг друга** (оба фабричных): `SteelCatwalks`, `Crane`, `Ventilation`, `Ground`-варианты,
`Window`-системы, базовый `MetalConstruction`, бочки/ящики/трубы (похожие).

**Уникально у IndustrialFactory:** 5 вариантов щитков, `OldHeater` (котёл), `WaterTank`+`WaterGauge`,
`GasCylinder`+`Gasbox`, более «машинный» кит (под завод-карту).

**Уникально у Warehouse:** фотоскан-декей, `PatchedWall`-декаль, мох/лужи, 47 ламп, крысы, следы-брызги,
кирпич-сеты, ткань-тряпки, заброшенная мебель.

## 4. Рекомендации (НЕ выполнял — на твоё решение)

1. **Для карты «Завод»** — выбрать ОДИН основной кит (рекомендую `IndustrialFactory` как более «заводской»),
   второй (`Warehouse`) — донор декей-ассетов для дома + резерв. ⚠️ сверить с тем, какой пак ты планировал под Завод.
2. **Для дома** — НЕ импортировать паки целиком в карту дома; перенести только cherry-pick (списки §1–§2)
   в отдельную папку, напр. `/Game/Avariika/Borrowed/` (трубы/кабели/щитки/котёл/газ-баллоны/декали/Niagara).
3. **Демо-карты обоих паков** (`Demo/FactoryDocks_*`, `Warehouse_01/02_P`) + их `*_BuiltData` (см. `OPTIMIZATION_REPORT.md`)
   — на геймплей не нужны, кандидаты на локальную архивацию (экономия ~6 ГБ BuiltData).
4. **Что точно НЕ тащить в дом:** краны, мостовые катвоки, станки, контейнеры, паровозы, foliage-кусты.
5. Физически удалять/двигать паки — **только после твоего «ок»** и по `asset-deletion-method` (закрыть редактор → rm,
   проверить `get_referencers`).
