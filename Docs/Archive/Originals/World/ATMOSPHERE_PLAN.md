## 2. ОСВЕЩЕНИЕ через лампочки (+ механика свет↔питание)
**Уже готово в КОДЕ:** `APowerSwitch.ApplyToFloods` гасит/зажигает лампы у акторов с тегом **`PoweredLight`** (`GetComponents<ULightComponent>` → SetVisibility). Рубильник уже рулит: потоп-электрификация + живой провод + **свет дома**. Размен: ВКЛ = светло, но провод/вода под током; ВЫКЛ = безопасно чинить, но темно → фонарь.
**Делаем (когда есть фикстуры в доме):**
- В каждый светильник/патрон — `PointLight`/`SpotLight` (тёплый ~3000–3500K, низкая интенсивность, чуть мерцания для хоррора).
- Тег актору-светильнику **`PoweredLight`** → щиток автоматически им рулит.
- Скрипт-заготовка: по списку меток фикстур добавить свет + тег (идемпотентно, как наши `Scripts/`). Координаты = после расстановки фикстур юзером.
- Мерцание/дребезг лампы перед выключением — таймлайн/материал emissive (атмосфера).
**Звук-пара:** гул питания `SC_Power_Hum_Loop` (собран) пока щиток живой; щелчок щитка `SC_Panel_Switch`.

## UDS night-пресет (точные значения — выставить за минуту)
Ориентир для `Ultra_Dynamic_Sky` (тюнить по картинке):
- **Time of Day:** ~22:30 (ночь, но не чёрная — луна как ключ).
- **Moon:** вкл, Moon Intensity ~0.1–0.3 (холодный лунный ключ-свет); Moonlight отбрасывает тени.
- **Clouds:** Cloud Coverage ~0.5–0.7 (рваные тучи, луна проглядывает); Cloud Speed низкая.
- **Fog:** Volumetric Fog вкл, плотность средняя (хоррор-дымка в коридорах/дворе).
- **Rain:** Weather → Rain ~0.4–0.7 (по крыше слышно — пара к `Rain_Medium_Metal_Roof` из базы); Wind лёгкий.
- **Гейт:** тяжёлые облака/дождь — через `EffectsQuality` (DefaultScalability.ini), VRAM 8ГБ беречь.
