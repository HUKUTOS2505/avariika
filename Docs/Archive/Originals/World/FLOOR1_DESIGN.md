## 2. ОТКУДА ПРИХОДЯТ ИГРОКИ (точки входа)

Сейчас 1 `PlayerStart` в гараже @(−1204, 94, 44). Логика концепта: **бригада аварийщиков приезжает
на вызов** (рация диспетчера дала адрес). Два сценария входа — рекомендую первый:

### ▶ Вариант A (рекомендую) — «Гаражный старт», заперты с бедой
- Бригада заехала на фургоне в гараж, ворота закрылись → **клаустрофобный старт** в духе RE7.
- **4 `PlayerStart`** рядом в гараже (кооп): сетка ~2×2 у точки (−1204, 94), z поднять на пол гаража.
  ⚠️ Сейчас старт z=44 — проверить, что это пол гаража, а не «под полом» (капсула ~88, может проваливать).
- Первый шаг игроков: гараж → дверь в дом (`HouseDoor_A` @420,−1042 или ближняя) → **холл-хаб**.
- Рядом со стартом — **вход в подвал** (под/у лестницы, `SM_Garage_Stairs`): главный кластер аварий внизу.
- Атмосфера: гараж тёмный (уже сделан «мрак» по WORKLOG), одна тусклая лампа, генератор у стены.

### ▷ Вариант B — «Парадный вход», классика
- 4 `PlayerStart` на крыльце у главной двери (юг-центр), бригада подходит с улицы под дождём (UDS-ночь).
- Минус: гараж/подвал-вход тогда «сбоку», теряется готовая клаустрофобная завязка.

### Нарративный вход (оба варианта)
1. **Рация** даёт адрес/тип вызова (см. `SPEC_Radio_Haggle.md`).
2. В холле — **`ACallBoard`** (доска вызовов): первая интеракция, выдаёт список аварий-задач этого дома.
3. **`AToolCase`** рядом — собрать/взять инструмент (хаб-сейв-рум, точка сбора бригады).
4. Дальше — петля RE7: из холла видно лестницу наверх; налево бытовые комнаты, направо гостиная/крыло.

## 3. ЗОНИРОВАНИЕ: мебель + аварии по макрозонам

Принцип: **наполнять кластерами вокруг аварий** (геймплейные узлы), а не равномерно — дом огромный,
равномерная расстановка → ощущение пустого склада. Каждый узел = авария + мебель-контекст + свет + звук.
Мебель — готовые BP из `AtmosphericHouse` (меблированный пак, см. `house-asset-packs`).

### 🅰 ГАРАЖ (СЗ, X[−1500…−700], Y[0…1000]) — старт + электро/вход в подвал
- **Назначение:** старт бригады, генератор, спуск в подвал.
- **Мебель/пропсы:** верстак (`BP_Workdesk`+`BP_Workdesk_extension`), стеллаж (`BP_Bookshelf`/`BP_Cabinet_*`),
  бочки/ящики/инструмент — **кандидаты из паков завода** (см. `FACTORY_PACK_AUDIT.md`), `StorageUnitsSet`.
- **Авария ⚡:** `Repairable_Generator` (генератор-стартер) у западной стены + рядом `APowerSwitch` (рубильник).
  Связка из кода: «генератор коротит при живом щитке» (`bGeneratorShortsIfPanelLive`) — наказание в момент успеха.
- **Свет:** `BP_Lamp_hanging_fluorescent` (мигает) + тег `PoweredLight`.

### 🅱 ЗАПАДНОЕ ЯДРО (X[−700…0]) — кухня + санузел + холл-хаб
- **ХОЛЛ-ХАБ** (у входа из гаража): `AToolCase` + `ACallBoard`, `BP_Lamp_chandelier`, лестница наверх в зоне видимости.
- **КУХНЯ 💧🔥:** `BP_Kitchen_counter_sink`, `BP_Kitchen_counter_A/B`, `BP_Kitchen_cabinet_A/B/C`, `BP_Stove`,
  `BP_Fridge`, `BP_Kitchen_counter_dishwasher`. Аварии: `Repairable_GasPipe` (плита/труба газа) + `Repairable_WaterPipe` (мойка).
  Узел «перекрой газ перед заваркой» (вентиль рядом).
- **САНУЗЕЛ 💧:** `BP_Toilet`, `BP_Bathroom_sink`, `BP_Bathroom_cabinet`, `BP_Showercurtain`. Авария: мелкий `Repairable_WaterPipe` (течь).
- **Свет:** `BP_Lamp_ceiling_round`/`_cone`, `BP_Lamp_bathroom_wall`. Все с тегом `PoweredLight`.

### 🅲 ЦЕНТРАЛЬНЫЙ БЛОК (X[0…1500]) — гостиная + столовая
- **ГОСТИНАЯ ⚡:** `BP_Bookshelf_fireplace` (камин!), `BP_Cabinet_A…D`, `BP_Side_table_A…D`, ковёр (декаль/меш).
  Главный **щиток `SM_ElectricBox`** + `APowerSwitch` здесь = «нервный узел» (свет ↔ ток). Авария ⚡: проводка/искрит.
- **СТОЛОВАЯ:** стол+стулья (нет в паке — meshy-плейсхолдер или из завода), `BP_Lamp_ceiling_circle`, шторы `BP_Curtains_long_*`.
- **Свет:** `BP_Lamp_standing`, `BP_Lamp_table_shade`, `BP_CeilingFan` (вращается — атмосфера). Тег `PoweredLight`.

### 🅳 ВОСТОЧНОЕ КРЫЛО (X[1500…5000]) — много комнат + лестницы
- Самая большая и пустая зона (DDDD/SSS на карте). **Риск пустоты — заполнять в последнюю очередь.**
- Кандидаты назначения: доп. спальни/кладовые/мастерская/проходные коридоры; одна комната — **второй кластер аварий**
  (чтобы крыло не было «мёртвым»): напр. прорыв трубы 💧 + лужа под током (если рубильник включён).
- Мебель: `BP_Dresser_A…C`, `BP_Wardrobe`, `BP_Bookshelf_6x`, `BP_Side_table_*`, шторы.
- ⚠️ **Вопрос юзеру:** не великовато ли крыло? Можно отрезать дальнюю часть (X>3500) под «запертое/недоступное»
  (заколоченные двери) — меньше дрессить, меньше нагрузка, плотнее хоррор. См. `OPTIMIZATION_REPORT.md`.

## 5. ПЛАН ОСВЕЩЕНИЯ (сейчас 7 ламп на 76 м — почти темно)

- Каждой комнате — 1–2 светильника `BP_Lamp_*` из `AtmosphericHouse` (см. зоны выше), тёплый 3000–3500K, низкая интенсивность.
- **Каждому светильнику — тег `PoweredLight`** → код `APowerSwitch.ApplyToFloods` автоматически гасит/зажигает их рубильником
  (механика «светло, но под током ↔ темно, но безопасно» уже в C++, `ATMOSPHERE_PLAN.md` §2).
- Мерцание перед выключением (таймлайн/emissive) — хоррор-деталь.
- Фонарь обязателен (`UFlashlight` уже есть) — подвал/тёмные комнаты.
- Скрипт-заготовка: по списку меток фикстур добавить `PointLight`/`SpotLight` + тег (идемпотентно). Координаты — после расстановки.
