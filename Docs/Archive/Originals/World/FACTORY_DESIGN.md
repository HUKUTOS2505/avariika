## 0. Статус и стартовая точка

- Карты Завода в проекте пока нет. Есть **готовая демо-сцена `FactoryDocks_01_P`** (IndustrialFactory) с сублевелами
  (Env ×5, Lighting Day/Overcast, Sounds, Effects) — **это бесплатная стартовая геометрия**: открыть, раздеть лишнее,
  переразметить под нашу петлю аварий. Альтернатива/донор декея — `Warehouse_01_P` (фотоскан, заброшка).
- Принцип тот же, что в Доме: **наполнять кластерами вокруг аварий**, а не равномерно; петли RE-стиля; гейты = починка.

## 1. Концепция — чем Завод отличается от Дома

| | Дом | Завод |
|---|---|---|
| Масштаб | тесные комнаты, бытовое | большие пролёты + тесные тех-туннели (контраст) |
| Аварии | бытовые (плита, мойка, щиток) | **промышленные** (котёл ВД, трансформатор, насосная, газгольдер) — крупнее, связаннее |
| Темп | камерный хоррор | каскады: одна авария питает другую через весь цех |
| Страх | дом «живой», скрипы | **эхо, изоляция, простор**, гул машин, пар из ниоткуда |
| Кооп | рядом, передачи | **разделение по цехам**, синхрон-отключения далёких мейнов, связь по рации рвётся |

Завод = «дом для взрослых»: те же 4 стихии (газ/вода/электро/огонь), но индустриального калибра и с длинными
причинно-следственными цепями (`IDEAS.md` → seeded job-graph: симптом наверху, причина за три зоны).

## 2. Вход бригады

- Авария масштабная → бригаду вызвали на объект (рация-наряд). Заезд через **проходную/ворота цеха** (Warehouse
  `WarehouseDoor_01` / IndustrialFactory ворота) или со двора-дока (`FactoryDocks`).
- 4 `PlayerStart` у въезда. Первый ориентир — **диспетчерская/щитовая = хаб** (`ToolCase`+`CallBoard`), оттуда виден
  главный пролёт цеха и таблички-маршруты.
- Нарратив: «ночная смена, никого, что-то рвануло» — пустой завод под дождём, аварийные лампы мигают.

## 3. Зоны (макроразметка)

1. **ДИСПЕТЧЕРСКАЯ / ЩИТОВАЯ (хаб)** ⚡ — safe-room: `ToolCase`, `CallBoard`, главный трансформатор/щит `ElectricBox_01..05`,
   `APowerSwitch` мейн (рулит светом всего завода — размен свет↔ток в цеховом масштабе). Окна в цех.
2. **ЦЕХ / КОНВЕЙЕР** 🔥⚡ — большой пролёт: станки, кабельные трассы по потолку (`Cable_01/02`), искрящая проводка,
   возможный пожар (`NS_Fire_Wall`). Открытое пространство = чувство уязвимости.
3. **КОТЕЛЬНАЯ / БОЙЛЕРНАЯ** 🔥💧 — `OldHeater_01` (котлы!), трубы ВД (`Pipe_01/02`, `Pipes_01..03`), манометры
   (`WaterGauge_01`), пар (`ns_ManholeSteam_Large`/`ns_SteamFast`). Узел «стравить давление / перекрыть перед заваркой».
4. **НАСОСНАЯ / КАНАЛ** 💧⚡ — `WaterTank_01`, насосы, затопление (FluidFlux), электрификация воды при живом мейне.
   Связка: обесточь → лезь в воду → но темно (фонарь). Прямая отсылка к `IDEAS` Sump Pump Race.
5. **ГАЗОВЫЙ УЗЕЛ / ГАЗГОЛЬДЕР** 🔥 — `GasCylinder_01`, `Gasbox_01`, газовые линии; утечка → облако → заварка = взрыв
   (как в Доме, но рушит секцию стены — Next Gen Destruction, gated по EffectsQuality).
6. **СКЛАД** — штабеля (`Barrel`, `Box`, `WoodPallet`, `Junks`), лут (хабар-идея), проходные/тупики, прятки от пара.
7. **ТУННЕЛИ / КОЛЛЕКТОР** 💧 — тесный низкий лаз под цехом (контраст простору): трубы, капель, потоп снизу,
   связь рвётся (рация дохнет — изоляция). Аналог подвала Дома.

## 4. Аварии по зонам (промышленный калибр)

| Зона | Авария | Механика (есть в коде) | Связка/каскад |
|---|---|---|---|
| Щитовая | главный трансформатор искрит | `Repairable_Wiring` ⚡ + мейн `APowerSwitch` | рулит светом ВСЕГО завода |
| Цех | оборванный кабель под током | живой провод ⚡ | бьёт; на мокром полу — каскад |
| Котельная | котёл ВД, прорыв пара/трубы | `Repairable_WaterPipe`/`GasPipe` 🔥💧 | стравить давление (`IDEAS` Pressure-Relief) перед заваркой |
| Насосная | затопление + насос | Sump Pump Race 💧 | завёл насос при живом мейне → КЗ + электровода |
| Газузел | утечка газа | `Repairable_GasPipe` 🔥 | заварка в облаке = взрыв секции |
| Туннели | прорыв коллектора | `Repairable_WaterPipe` 💧 | потоп поднимается снизу, давит вверх |

**Фишка Завода — кросс-зонные цепи** (`IDEAS` catastrophe-combo + dual-main shutoff): газовый мейн в газузле,
электрический — в щитовой, на разных концах. Чтобы погасить аварию в цеху — синхронно отключить ОБА (разделиться,
счёт по рации). Это «дом для взрослых» версия гейтов починки.

## 5. Гейты и маршруты (петли RE-стиля)

- Главный пролёт цеха = хаб-перекрёсток; крылья (котельная/насосная/газузел/склад) расходятся, открываются по ходу.
- Гейт-примеры: заклинённая роль-ставня открывается только после запуска резервного генератора; затопленный
  туннель проходим после откачки; искрящий мейн надо обесточить, чтобы пройти мокрый цех.
- Короткие срезки (катвоки/лестницы Warehouse `Handrails_01`) открываются позже — backtracking без скуки.

## 6. Кооп-моменты (из `IDEAS.md`, ложатся на Завод идеально)

- **Two-Carry Heavy Haul** — тащить резервный генератор/насос вдвоём по узким лестницам/катвокам.
- **Synchronized Dual-Main Shutoff** — газ-мейн и электро-мейн в разных концах, окно в пару секунд.
- **Lockout двух рубильников** — высокоамперный КЗ в насосной гасится главным + суб-щитком одновременно.
- **Связь рвётся в туннелях** — нужен «человек-репитер» между диспетчерской и низом.
- **Vent-Then-Weld** в котельной — один вентилирует пар/газ, другой варит вслепую.

## 7. Переиспользование ассетов (НЕ строить с нуля)

- **База геометрии:** `FactoryDocks_01_P` + сублевелы (Env ×5) — раздеть демо-наполнение, оставить костяк цеха/доков,
  переразметить под зоны §3. Lighting_Overcast сублевел — хорош под хоррор-настроение.
- **Декей/заброшка:** `Warehouse` — `MetalRustyWall_01`, `PatchedWall`, мох/лужи, ржавые стены/полы, 47 ламп,
  кирпич, крысы-Niagara, следы-брызги. Делает завод «мёртвым».
- **Меши-инфраструктура:** котлы/трубы/щитки/баки/газ-баллоны/вентиляция/кабели (полный список — `FACTORY_PACK_AUDIT.md`).
- **Niagara/звук:** пар/огонь/искры/дым + промышленный амбиент (Warehouse `Audio/`: машины/цепи/пар/скрипы металла).
- ⚠️ **НЕ тащить** в playable: краны/мостовые катвоки-гиганты/станки-исполины/foliage — масштаб и VRAM.

## 8. Атмосфера / свет / звук

- Свет: аварийные мигающие промлампы (`Warehouse Lamp_01/02`) + мейн-рубильник рулит (тег `PoweredLight`). Brown-outs
  (`IDEAS` просадка щитка) на заводе особенно уместны — гул трансформатора растёт.
- Звук: цеховой гул, капель в туннелях, свист пара, эхо шагов в пустом пролёте, дождь по металлокрыше.
- Погода: UDS-ночь + гроза (молния через фонари цеха; разряд может выбить мейн — `IDEAS` гроза рулит светом).

## 9. Оптимизация (Завод тяжёлый — беречь 8 ГБ VRAM)

- Это самая тяжёлая из 3 карт (37 ГБ исходных паков). Строить из **cherry-pick**, не из полного демо.
- Отрезать недоступные дальние секции (заколоченные ворота) — меньше Nanite/Lumen на экране.
- Гейтить пар/огонь/воду/destruction через `EffectsQuality` (`OPTIMIZATION_REPORT.md`).
- Демо-`*_BuiltData` FactoryDocks (1.6 ГБ ×2) — не нужны для нашей карты; пересобрать свет под свою разметку.
- Per-map scalability override, если давит VRAM.
