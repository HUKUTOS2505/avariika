# HOUSE_PLAN — карта-дом «Аварийки» (чертёж + механики)

> Рабочий план уровня-дома. Строим **только дом** (без большого окружения, компактный двор).
> План **не зависит от ассет-пака** — переедет на любой набор модулей.

## Решение по ассет-паку (2026-06-16, обновлено)

Старый `PostApocalypticHouse` (постапок-руина) **удалён** — не наш сеттинг. Импортируем **3 пака реалистичных домов**, дедуп между Residential:

| Пак | Роль | Сильные стороны |
|---|---|---|
| **AtmosphericHouse** (`/Game/AtmosphericHouse/`, 1633 ассета) — импортирован ЦЕЛИКОМ | резерв/«старый-worn» вид + **подвал-модули** + свапер clean↔worn | basement, walls in/out/basement, demo-карты |
| **Residential Houses Vol.1** | реалистичный пригород, **меблированные** дома | интерьеры обставлены из коробки |
| **Residential Houses Vol.2** | реалистичный пригород, больше коробок + мебель/кухня/household props | 9 домов, full modular kitchen |

**Финальную базу дома выбираем после разбора структуры:** Residential (реалистичный модерн) — приоритет на ВИД дома; AtmosphericHouse — источник **подвала/котельной** (которых у Residential может не быть) + опция worn-свапера.

Минусы паков НЕ мешают:
- «Нет функции открытия дверей» → свой C++ `ADoor` (любой меш).
- «Capsule Radius ≤45» (Atmospheric) → наш персонаж radius **34**, проходит.
- «Max Loop 2 000 000 для свапера» → галка в Project Settings.
- «Глюк static lighting 5.5.3/5.6» → мы на **5.7 + Lumen**.

**Статус (2026-06-16 ночь):** AtmosphericHouse скопирован в `Content/AtmosphericHouse/` (9.3 ГБ). Residential Vol.1 + Vol.2 распаковываются из RAR → дедуп → импорт не-дублей. Дальше — разбор структуры + сборка по плану.

**Переносится без изменений** (наши системы пак-независимы): `ADoor`, вода (`Repairable_WaterPipe` + разлив + электрификация + сапоги), газ, электрика, рубильник `APowerSwitch`, паника/витали, инвентарь.

## Общая структура дома

5 уровней: **подвал + 1 + 2 + 3 этаж + чердак**. Гараж слева, крыльцо/выход во двор спереди.
Компактный двор вокруг (сарай, колодец, теплица, люк — по желанию, фаза 3).

Условные обозначения утечек: 💧 вода · ⚡ электрика · 🔥 газ.

**Связи 1-го этажа:**
- Лестница на 2 этаж — широкая, с перилами, естественный свет через окно.
- **Дверь в подвал** под лестницей → технический подвал (котельная, насосы, электрощитовая, мастерская).
- **Выход во двор** через кухню → крыльцо, сад, колодец, теплица, сарай.

**Пути:** основные / дополнительные / спуск в подвал / выход во двор (как на чертеже).

## Подвал (фаза 1, ключевой)

Технические помещения — сердце механик аварий:
- **Котельная** — 🔥 газовый котёл (утечка газа), 💧 трубы.
- **Насосная** — 💧 прорыв труб, электрифицированный разлив.
- **Электрощитовая** — ⚡ главный рубильник (`APowerSwitch`), проводка.
- **Мастерская** — инструменты, верстак.

## Этажи 2-3 + чердак (фаза 2)

- 2 этаж: спальни 1-3, кабинет, С/У, балкон. 💧 в спальне 1.
- 3 этаж: спальни 4-5, комната отдыха, С/У, балкон.
- Чердак: 💧/⚡ проводка на чердаке.

## Порядок стройки (фазы)

1. **Фаза 1 (слайс):** подвал + 1 этаж в компактном дворе. По 1 утечке каждого типа (💧🔥⚡) на готовых системах → играбельный цикл 15-20 мин.
2. **Фаза 2:** этажи 2-3 + чердак, больше утечек, доп./секретные пути.
3. **Фаза 3:** двор — сарай, колодец, теплица, подземный люк.

**Тех.заметки при стройке Pack 1:**
- Снап к сетке (модули стык в стык).
- Лестничный стояк сквозной по этажам (вырез в полу под проём).
- Project Settings → Max Loop Iteration Count = 2 000 000 (для свапера).
- Освещение — Lumen (не static), за образец тёмный/horror-сетап.
