# Структура проекта «Аварийка» — что за что отвечает

_Карта проекта: где что лежит и зачем. Обновлено 2026-06-16 (после реорганизации папок)._

---

## 📁 Content (`/Game/...`) — ассеты

### Наш контент
| Папка | За что отвечает |
|---|---|
| **`Avariika/`** | НАШ контент. `Blueprints/` (BP_AvaryoGameMode, BP_AvaryoCharacter, предметы), `Maps/` (рабочие карты), `blueprinsTest/` (песочница: BP_GameMode/BP_Pawn/BP_PlayerController для учёбы на карте Test), UI. |
| **`Avariika/Maps/`** | Карты игры: **`Lvl_FirstPerson`** (рабочий объект, весь геймплей — 94 актора), `Test` (учебная песочница), `L_MainMenu`, `L_AnimTest`. |
| **`Audio/`** | НАШИ звуки (`SFX/...`) — шаги, сварка, взрыв, искры, рация, кофе/аптечка и т.д. Жёстко прописаны в C++. |
| **`hazmat/`** | Модель оператора (скелетный меш + материалы костюма). Тело персонажа. |
| **`Characters/`** | Скелет/меши оператора и манекены, ретаргетнутые анимации (Op_…). |

### Чужие паки
| Папка | За что отвечает |
|---|---|
| **`_Packs/`** | 🆕 Чужие/скачанные паки (29 шт.) сложены сюда — плейсхолдеры до своих моделей. Анимации, пропы, звуки. Не используются игрой. _(Ещё 3-4 пака — Gore, JKMotion, ResourcePack — застряли в корне из-за кросс-связей между паками; дочистим с закрытым редактором.)_ |
| **`PostApocalypticHouse/`** | «Дом» — будущая красивая карта-объект (World Partition, ~5 ГБ). Карты в `Maps/` (LV_Horror_Light и др.). _Переименование в `moduleHouse` — запланировано._ |
| **`Hospital/`, `NiagaraExamples/`, `NiagaraExplosion01/`, `Survival_SFX/`, `EasyOptionsMenu/`** | Используются игрой/кодом как заглушки (эффекты взрыва, звуки UI, меню) — оставлены в корне, т.к. вшиты в C++/карты. |
| `Input/`, `LevelPrototyping/`, `FirstPerson/` | Движковый/шаблонный контент (Enhanced Input, серые материалы прототипа, остатки FP-шаблона). |

> ⚠️ Все чужие паки — **плейсхолдеры**: до релиза заменяем на свои модели (meshy.ai) + докупаем лицензии.

## ⚙️ Source/Avaryo — C++ код (модуль `Avaryo`)

### Персонаж и компоненты
| Файл | За что отвечает |
|---|---|
| **`AvaryoCharacter`** | Главный персонаж: инвентарь (1 тяжёлый + 4 слота), движение/бег/присед/прыжок, камера 1↔3 лицо (V), взаимодействие (E), бросок/передача, толчок (Q), использование предметов, оператор-монитор (Tab). |
| **`Components/UVitalsComponent`** | Шкалы: HP, паника, выносливость, туалет. Эффекты ранения/паники, безопасная зона хаба. |
| **`Components/UFlashlightComponent`** | Налобный фонарик: вкл/выкл, мерцание, blackout при скачке напряжения. |

### Мир / объекты
| Файл | За что отвечает |
|---|---|
| **`World/ARepairable`** | ❤️ Ядро: ремонтируемые объекты (щиток/труба/генератор). Этапы починки, мини-игры (курсор/вентиль/стартер), **газ-утечка** (облако, взрыв), **🆕 потоп** (разлив + ток в воде), колхозный ремонт. |
| **`World/APowerSwitch`** | 🆕 Рубильник (каскад «вода»): обесточить залитую зону, чтобы не било током (порядок-наказание). |
| **`World/AExitZone`** | Зона эвакуации (ГАЗель): зелёный маяк «на базу», когда всё починено. |
| **`World/ACallBoard`** | Доска заявок в хабе: взять заявку → выезд на объект (ServerTravel). |
| **`World/AToolCase`** | Ящик инструмента в хабе: собрать кит перед выездом. |
| **`World/AToilet`** | Биотуалет (туалетная шкала, мини-игра). |
| **`World/ATrap`, `AFloodlight`, `ABioProjectile`** | Растяжки/ловушки, прожектор, биоснаряд (санитарный инцидент). |

### Предметы
| Файл | За что отвечает |
|---|---|
| **`Items/APickupItem`** | Подбираемый предмет (инструменты/расходники): ToolTag (Welder/GasDetector/RubberBoots…), вес, заряды, эффекты (аптечка/сигареты/кофе/огнетушитель). |
| **`Items/ABioPickup`** | «Подозрительный комок» (биоснаряд для броска). |

### Игра / режимы / сеть
| Файл | За что отвечает |
|---|---|
| **`Game/ARunState`** | Состояние забега: задачи (что починить), «Акт» (победа/провал), пулы реплик диспетчера, эмбиент-саундскейп, скриптовый ре-трип щитка, хаб-режим. |
| **`Game/UDispatchSubsystem`** | Леджер хаба (переживает ServerTravel): домашняя карта, активная заявка, собран ли кит. |
| **`Game/MenuGameMode`, `AvariikaOnlineSubsystem`** | Главное меню; кооп-сессии (AvHost/AvJoin, листен-сервер). |
| **`UI/AvaryoHUD`, `MenuHUD`** | Игровой HUD (шкалы, подсказки [E], прицел, газоанализатор) и меню. |

## 🎮 Как это собирается в игру (петля)

```
ХАБ: доска заявок (ACallBoard) → собрать ящик (AToolCase) → выезд
  → ОБЪЕКТ (Lvl_FirstPerson): диагностика → починка по порядку (ARepairable:
     щиток/газ/вода/генератор) — ошибка порядка = ток/потоп/взрыв/пожар
  → всё починено → зелёный маяк (AExitZone) → к ГАЗели
  → «Акт» (ARunState) → деньги → база → следующая заявка
```
Шкалы (UVitalsComponent) + фонарь (UFlashlightComponent) + шум (задел под монстра) держат напряжение. Диспетчер (UDispatchSubsystem) ведёт по рации.
