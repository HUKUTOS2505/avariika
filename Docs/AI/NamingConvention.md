# Naming Convention

Primary reference: [PROJECT_BRAIN.md](../../PROJECT_BRAIN.md).

- C++ classes follow Unreal prefixes: `A`, `U`, `F`, `E`.
- Project gameplay C++ uses the `Avaryo` module/API prefix.
- Actor class filenames currently use class-like names such as `ARepairable.h`, `APickupItem.h`, and `ARunState.h`.
- Blueprint names should stay descriptive and Unreal-standard, for example `BP_AvaryoCharacter`.
- Avoid renaming assets or classes during unrelated work; redirects and Blueprint references are expensive.
