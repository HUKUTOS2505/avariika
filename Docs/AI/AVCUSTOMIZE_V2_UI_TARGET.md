# AvCustomize V2 UI Target

## Цель

`WBP_CharacterCustomizationRoot_V2` — полноэкранное меню кастомизации, построенное по композиционному принципу референса, без его копирования пиксель-в-пиксель.

Целевая композиция:

- `TopBar` — вкладки основных разделов.
- `LeftPanel` — категории активного раздела.
- `PreviewArea` — крупная центральная область для будущего `SceneCapture`.
- `RightPanel` — настройки выбранной категории.
- `BottomArea` — randomize и экипированные модули.

## Вне текущего этапа

Пока не реализуются:

- голос;
- походка;
- позы;
- типы телосложения;
- валюты;
- инвентарь;
- `CommonUI` / `GameViewportClient`;
- `SceneCapture`;
- `SaveGame`.

## Граница визуального решения

Композиционный принцип референса используется только как ориентир структуры. Финальный дизайн, размеры и отступы утверждаются пользователем вручную.
