# Аварийка — Концепт игры

## Суть
Кооперативный **хоррор-комедийный** симулятор аварийной бригады. 1-4 игрока — операторы аварийной службы: получают заявки, выезжают на объект, чинят аварии (электрика, газ, прорывы и т.д.), а параллельно на объекте творится **что-то ненормальное** (монстр/аномалия). Тон: серьёзная работа + чёрный юмор + нарастающий хоррор. Эстетика — **реалистичный модерн** (НЕ совок/сай-фай/фэнтези/мультяшность): оранжевый hi-vis, газмаски, каски, реальный инструмент.

## Игровой цикл (мета-петля)
```
ХАБ (база) → получить ЗАЯВКУ от диспетчера → собрать ИНСТРУМЕНТ в ящик →
загрузить в МАШИНУ → ВЫЕЗД на объект → РАБОТА на объекте (чинить + выживать) →
вернуться → отчёт/награда → следующая заявка
```

### Хаб (база бригады)
Общая комната-база, где игроки находятся между заявками:
- **Доска/терминал заявок** — диспетчер выдаёт задачу (какой объект, тип аварии).
- **Стеллаж инструмента** — берёшь нужный инструмент, **складываешь в ящик** (общий кейс бригады).
- **Машина (Газель/фургон)** — грузишь ящик в кузов, садитесь, выезд.
- Социалка: эмоуты/жесты между игроками (рукопожатия/празднования — из набора эмоутов), подготовка, болтовня.

### Диспетчер
- Выдаёт заявку **голосом** (озвучка — записать/синтез TTS). Радио-связь в духе реальной аварийной службы.
- По ходу заявки может докидывать вводные/подсказки по рации.

### Карты (объекты заявок)
1. **Дом** (жилой/частный) — бытовые аварии.
2. **Завод** (промышленный) — крупные системы, газ, электрика, опасные зоны.
3. **Больница** — людная/тревожная среда.
4. **Корабль** — *на будущее* (после основных трёх).

Каждая карта = объект с набором поломок + своя «аномалия»/монстр-сценарий.

### Транспорт
- Машина бригады (фургон/Газель) — кузов под ящик инструмента, выезд из хаба на карту (загрузочный/режиссёрский переход или драйв).

## Ключевые механики (на объекте)
- **Ремонт** — основная: чинить узлы (щиток/панель/проводка/вентиль/рубильник) с инструментом, таймингом/мини-взаимодействием. Кооперативно (двое держат/один крутит).
- **Инвентарь** — «**1 тяжёлый предмет на земле + 4 слота**» (тяжёлый кейс/агрегат носится в руках, мелочь в слотах).
- **Расходники** — бинт/аптечка (лечение), питьё/термос, и т.п.
- **Состояния**: HP, **шкала паники**, шкала «туалета» (комедийная), газ/раздражители (кашель, шатание).
- **Даун/откачка** — упал → тиммейт поднимает (revive).
- **Рация** — связь с диспетчером и между игроками.
- **Хоррор-триггеры** — монстр рядом → подмена обычной ходьбы на испуганную, скачки паники, скример-флинч, прятки.

## Монстры (на паузе по сборке — ресурсы собраны)
- 🐕 **Собака-монстр** — четвероногий, охотится/преследует. Готовый пак AnimX German Shepherd (свой скелет + AI + полный мувсет). Под прототип готов.
- 👂 **Слухач** — гуманоид-существо, **охотится на ЗВУК** (как «кликер»): шуми — найдёт. База: зомби-пак (ползание/дормант/walk) + Boss-пак (атаки). Plant Monster — отдельный стационарный враг-ловушка (бонус).

## Персонажи
- **Оператор (игрок)** — аварийщик в hi-vis + газмаска + каска + инструмент.
  - **Релиз:** купленный Fab-воркер на **чистом Epic-скелете** (+IK-кости), модульный (маски/каски/инструмент вкл./выкл.), перекрас ID-картами в оранжевый. Целевой скелет проекта = **Epic/UE Mannequin**.
  - **Сейчас:** Meshy-прототип (плейсхолдер, в релиз не идёт).
- Бригада = до 4 операторов (кооп).

## Анимации (статус)
- **142 заретаргеченных `Op_*`** на операторе (локомоция все направления, присед, раненый/ползание, даун/откачка, удары, смерть, ремонт, подбор/обыск/интеракт, расходники, эмоции/хаб-эмоуты, состояния).
- Запас исходников: ~20 паков (Paragon/GAS/Motifect/MoCap/ASP/Interaction/Loot/Work и др.) — на Epic-персонаже играют напрямую/чистым ретаргетом.
- Дыры (нужен Control Rig/парные): нести ТИММЕЙТА на руках, парное рукопожатие.
- Подробности: `ANIM_HAUL_PLAN.md`, `ANIM_REVIEW_CHECKLIST.md`.

## Аудио

## Технадзор

- Целевой скелет — Epic Mannequin (после смены персонажа).

# АВАРИЙКА — Концепт 2.0

> Кооп-хоррор-комедия для Steam. Обновлено с учётом ВСЕХ нововведений: исходный концепт (`промт.docx`) + `IDEAS.md` + реально написанный код + стратегия «масштаб DRG».
> Версия 1.0 (формула, инвентарь, роли, шкалы, отчёт-мем) — цела и в силе. Здесь она дополнена тремя большими слоями и приведена в соответствие с тем, что уже построено.

## 0. Что изменилось с версии 1.0 (кратко)

Ядро вижна то же: ночная аварийная бригада, хаос с друзьями, монстр-угроза, отчёт-мем. Добавились **три стратегических слоя**:

1. **Северная звезда — масштаб Deep Rock Galactic.** Не разовый угар на вечер, а **долгий ретеншн**: роли-классы с глубиной + прокачка (моды/оверклоки) + косметика-функция + престиж + Hazard-тиры. Каждую фичу мерим вопросом «добавляет ли это реиграбельности».
2. **Идентичность игрока.** Создай своего работягу: старт «бомж» (тишка/джинсы) → зарабатываешь на каску, спецовку, ботинки, инструмент, маску. **Косметика = функция.**
3. **Движок реиграбельности.** Процедурные цепочки аварий (заявка ВРЁТ), эскалирующие смены с остаточным состоянием, колода мутаторов, район с памятью.

И производственная реальность: **многое УЖЕ в коде** — кооп-бэкенд (EOS), голос (рация STT/TTS), модульный персонаж с кастомизацией, локомоция, 13 языков, телесные дебаффы, экономика/репутация/диспетчер. Финальные анимации — через мокап. Текущие ассеты-паки — плейсхолдеры.

## 1. Формула и питч

**ГЛАВНАЯ ФОРМУЛА:** Lethal Company + Phasmophobia + аварийная бригада + бытовой идиотизм + опасные инструменты. **80% угар и хаос с друзьями, 20% настоящий страх.** Поверх — **DRG-глубина прогрессии**, чтобы возвращались месяцами.

**Питч:** «Аварийка» — кооп-хоррор-комедия на 1-6 игроков. Ночная аварийная бригада приезжает чинить опасные объекты: щитки, газ, трубы, генераторы, насосы, кабели. Игроки таскают инструменты, ставят камеры, орут в рацию, тушат друг друга огнетушителем, оживляют тиммейтов и пытаются уехать живыми — и с навара, а не в минус.

**КЛЮЧЕВОЙ АКЦЕНТ:** главный враг — не только монстр. Половину проблем создаёт сама команда: курит рядом с газом, шумит, теряет инструменты, включает рубильник не вовремя, паникует.

---

## 2. ⭐ Северная звезда: масштаб DRG (мерило всех решений)

Цель — не «поиграли вечер и забыли», а **сотни часов** как в Deep Rock Galactic. Что это требует:

- **Роли → классы с глубиной.** Роль (электрик/сварщик/разведчик/оператор/носильщик/медик) перестаёт быть просто «кто что взял из багажника» и обрастает **специализацией, апгрейдами, перками** (см. §6). Базовая доступность сохраняется (взял предмет — выполняешь роль), но есть куда расти.
- **Прокачка: моды / оверклоки.** Инструмент и снаряжение качаются (модификаторы поведения, рискованные «оверклоки» — больше пользы ценой нового риска). Аналог DRG-оверклоков.
- **Косметика = функция + статус.** Шмот не только красит, но и работает (маска/ботинки/перчатки = механика); редкая косметика = флекс за гринд/престиж.
- **Hazard-тиры.** Сложность смены настраивается (как DRG Hazard 1-5): больше аварий, агрессивнее монстр, злее экономика, новые мутаторы. Выше тир = выше навар и репутация.
- **Престиж / длинный хвост.** Сезонный/престиж-сброс ради статусной косметики и званий; «Район с памятью» (см. §15) даёт бесконечный процедурный контент.

**Правило:** прежде чем добавлять фичу — спроси «она углубляет реиграбельность/ретеншн или это разовый гэг?». Гэги допустимы, но костяк должен работать на возврат.

---

## 3. Геймплей одного забега

1. Бригада приезжает на объект на аварийной машине (**Hilux/Газель**, кузов = лоадаут).
2. Из багажника выбирают инструменты и расходники (можно нормальные или **дешёвые ради навара** — `bCheapGear`).
3. Получают заявку от диспетчера: «обычная поломка на 5 минут».
4. На объекте выясняется: монстр, аварии, газ, темнота, хаос. **Заявка ВРЁТ** — реальная причина глубже (процедурная цепочка симптом→корень, §15).
5. Команда выполняет задачи: ищет предохранители, чинит щиток, варит трубу, тянет кабель, запускает генератор/насос.
6. Игроки решают: спасать раненого, доделывать задачу или уезжать.
7. Финал: уехать живыми с наваром, провалить заявку или устроить катастрофу. → **Отчёт-мем** (§13).

**Смена = очередь нарядов** (3-5), а не один забег: недочинил → переносится в следующий вызов худшим стартом (§15).

---

## 4. 🆕 Идентичность игрока: создай работягу + прогрессия снаряжения

*(реализуется на модульном Quantum-персонаже; кастомизация одежды/волос/цвета уже в коде)*

- **Создание персонажа.** Игрок собирает своего работягу: тело, волосы/борода, одежда, цвет. Старт — **«бомж»**: тишка + джинсы, без снаряжения.
- **Прогрессия = снаряжение.** За навар покупаешь и надеваешь: **каска** (защита от падающего/удара), **респиратор/маска** (газ/CO), **спецовка/комбез**, **ботинки** (ток/скольжение), **перчатки** (поднять био/горячее), **жилет** (слоты/видимость). **Косметика = функция:** надетое реально работает в механиках.
- **Связь с сейвом.** Снаряжение и косметика — персистентный прогресс (бомж → профи). Снаряжение-флаги уже хранятся в сейве (`bHelmet/bGasMask/bGloves` и т.п.) — даём им визуал и геймплей.
- **DRG-хвост:** редкие скины/раскраски за гринд/Hazard/престиж = статус и флекс в коопе.

## 5. Инвентарь — простая и сильная система

Не RPG-инвентарь. **1 большой предмет в руках + 4 быстрых слота + экипировка.**

| Тип | Примеры | Правило |
|---|---|---|
| **Большой предмет в руках** | сварочник, генератор, катушка кабеля, насос, лестница, баллон | занимает руки, замедляет, надо ставить на землю |
| **Быстрые слоты 1-4** | сигареты, зажигалка, изолента, предохранитель, ключ, детектор, запасной фонарь | достаются быстро, без меню |
| **Экипировка** | налобный фонарь, рация, каска, нагрудная камера, маска, ботинки | всегда с игроком, но может садиться/глючить |

**Правило сварочника:** занимает руки; мелочь из слотов достаёшь свободно, но другой большой предмет — только поставив сварочник.

## 6. Роли = предметы (углублены до классов)

**База (как было):** роли не фиксируются в меню — кто что взял из багажника, тот ту роль и тащит. Проще, смешнее, лучше для коопа.

**DRG-углубление (новое):** у каждой роли — **специализация + апгрейды + перки**, чтобы было куда расти (см. §2, §14).

- **Электрик** — тестер, изолента, предохранители. Чинит щитки, проверяет ток, питание по секторам. Апгрейды: изолированные перчатки, мультиметр-сканер, заземление (§11). Риск: удар током.
- **Сварщик** — аппарат, маска, огнетушитель рядом. Варит трубы, режет замки/ворота. Шумит, светится, опасен при газе. Апгрейды: быстрый розжиг, тихая дуга. Слеп в маске → доверяет «чисто!».
- **Разведчик** — мощный фонарь, датчик движения, мел/спрей. Ищет комнаты, метит путь, первым в подвал, отвлекает шумом.
- **Оператор** — планшет, рация, камеры, карта. Видит камеры бригады/объекта, предупреждает, рулит светом/дверями. Отдельная статистика (§13).
- **Носильщик** — катушка, генератор, ящик. Тащит тяжёлое (TWO_PERSON-связка, §9), тянет кабель, выносит раненых.
- **Медик/санитар** — аптечка, нашатырь (`Ammonia` уже будит), дефибриллятор. Поднимает, оживляет, снижает панику, спасает забег.

---

## 7. Шкалы игрока, статусы, телесные дебаффы

**Шкалы (на старт обязательно):** HP, **Паника**, **Позыв в туалет**, **Выносливость**. Не ради реализма — ради смешных и страшных кооп-ситуаций.

- **HP** — урон от монстра, тока, падения, взрыва, огня, газа, воды под напряжением. На нуле — не сразу смерть: «ранен / без сознания» → команда спасает (§ ниже).
- **Паника** — растёт от темноты, одиночества, крика монстра, смерти друга, помех в рации, «ОН ЗА ТОБОЙ». Высокая: трясутся руки, сложнее чинить, фонарь дрожит, громкое дыхание, роняет предмет, **сам выдаёт фразы** (монстр слышит). Снижается светом, тиммейтом, сигаретой, успешным ремонтом, машиной, нашатырём.
- **Туалет** — комедийная: растёт со временем/страхом/газировкой. Высоко — хуже бег, нервные реплики, пердёж выдаёт позицию. Максимум — **санитарный инцидент** (дебаф, шум, паника, строка в отчёте).
- **Выносливость** — бег, таскание тяжёлого, перенос раненого, паническое спасение. Быстрее падает под газом/с грузом.

**🆕 Телесные дебаффы (УЖЕ в коде):** икота (`HiccupInterval` дёргает курсор починки), отдышка (`Winded` расширяет дрожь), стан от выдоха (`ExhaustStun`). → **Витал-саботаж починки:** спешка тела ломает мини-игру (кооп: напарник держит зону, пока бегаешь к биотуалету).

**Ранения/смерть/оживление:**
| Состояние | Что | Спасение |
|---|---|---|
| Ранен | ползает, плохо видит, шепчет в рацию, держит мелочь | поднять на месте |
| Без сознания | лежит, слышит глухо, монстр добивает | аптечка/нашатырь/донести к машине |
| Мёртв | призрак, чуть помогает/вредит | дефибриллятор, редкий предмет, мини-игра у машины |

**Статусы** (меняют поведение, не просто UI): Испуган, Паникует, Трясутся руки, Хочет курить, Хочет в туалет, Санитарный инцидент, Испачкан, Воняет, Под током, Оглушён, Ослеплён пеной, Задымлён, Отравлен газом, Временно мёртв.

## 8. Хоррор без монстра (атмосфера — работает уже сейчас)

*(монстр отложен; эти системы держат страх без него)*

- **Дом дышит** — директор скрипов: `SC_Creak` из точек ЗА/НАД игроком, частота растёт с паникой/таймером, изредка качнуть пустую `ADoor`. *(при разделении каждому скрипит рядом → «это ты наверху?» — «я в подвале…»)*
- **Авария растёт сенсорно** — газ сочится под двери (гуще дым+шипение+мухи), вода поднимается по этажам (FluidFlux), огонь ползёт по стене; две аварии встретились → каскад во взрыв/электродом.
- **Просадка щитка / brown-outs** — живой щиток копит нагрузку, гул растёт по питчу, лампы дребезжат, за порогом — дуга + провал в темноту 2-4с. Свет, которому нельзя верить.
- **Подвал — врата страха** — смена room-tone, капель громче, дверь захлопывается за бригадой, единственный свет — на щитке наверху.
- **Газовый бред** — долгая экспозиция: гуще мухи, глухой звук+сердце, стингер, силуэт на кадр, «дверь кажется открытой». Клиентский визуал, лечится маской.
- **Гроза рулит светом** — гром-вспышка в окна (бесплатный кино-свет), близкий разряд выбивает щиток, силуэтит вешалку/жильца на кадр.
- **Прошлая бригада** — статичный сторителлинг: брошенный ящик, упавший мерцающий фонарь, записки «НЕ ВКЛЮЧАТЬ ЩИТОК», стул подпёр дверь подвала, неподвижный хозяин в кресле. Ничего не двигается — потому жутко.
- **Связь рвётся** — диспетчер единственный человеческий голос; глохнет в подвале/грозу/панику.

## 9. Кооп-механики (углублённый кооп — ядро возврата)

- **CoopHold-починка** — новый тип `ARepairable`: фикс требует ДВУХ тел (колесо вентиля вдвоём, держать крышку щитка пока второй внутри, хомут пока варят). Прогресс идёт, только пока ОБА держат; отпустил → откат + брызги/искры.
- **Two-Carry тяжёлое** — груз с тегом TWO_PERSON: соло ползком со стаггером, вдвоём быстро, но жёсткой связкой («левее! другое лево!») по узкой лестнице.
- **Электрифицированная вода — цепь спасения** — напарник упал в воде при живом щитке → спасатель тоже падает. Цепь: A гасит щиток (в темноту), B тащит тело, C бинтует на сухом. Порядок не тот = два трупа.
- **Lockout двух рубильников** — сильный КЗ в воде гасится ТОЛЬКО удержанием главного + суб-щитка в разных комнатах одновременно. Отпустил рано — ток вернулся. *(счёт по рации «на три…»)*
- **Vent-Then-Weld** — газ у трубы копится заново; один вентилирует, другой варит вслепую. Искра до очистки = взрыв. *(friendly-fire: сварщик слеп и верит «чисто!»)*
- **One Mask, Four Lungs** — одна маска на бригаду, передают; упал в облаке — спасатель тащит или «надышать» через маску до двери, рискуя своим воздухом.
- **Stay-On-The-Line** — один заперт на рации-торге (уязвим, push-to-talk), остальные тушат; рычаг растёт с активной опасностью → соблазн «пусть погорит для навара».
- **Таскание тиммейта** — за руки, через плечо, в тележку, в шкаф, до машины. *(один тащит, второй светит, третий держит дверь, четвёртый по ошибке закрывает её перед всеми)*

## 10. Юмор / слапстик

- **Огнетушитель — не оружие, а 2-5 сек спасения** (слепит, замедляет, сбивает атаку) + **реактивная отдача** (`Extinguish`/`AFoamPatch` есть): толкает назад, на мокром/пене — ragdoll-проезд; струя в напарника = пол-экрана пены.
- **Заклинило рацию (хот-майк позора)** — перегретая рация залипает в ON, транслирует диспетчеру всё → штраф через леджер + комментарии. Глушить — стукнуть.
- **Цепной завал / домино** — поскользнулся с холодильником → роняешь, катится, сбивает напарников, щёлкает рубильник/валит прожектор.
- **Акт выполненных работ** — перед выплатой диспетчер требует заполнить планшет (мини-игра курсор) посреди дымящегося дома; промах → урезка выплаты.
- **Жилец-вредитель** (`CitizenNPC`, нужен BT/навмеш) — «помогает»: включает рубильник обратно, распахивает двери, хватает за рукав, паникует (`FearContagion`).
- **Жадность: вынос телевизора** — ценности как Heavy: донёс → бонус, но руки заняты, тормозит, спалили → штраф больше навара.
- **Не тот инструмент** — открыть щиток ломом, замотать трубу изолентой, ударить генератор ключом. Иногда работает, но риск/шум/штрафы.
- **Матерящийся диспетчер** (`DispatchSubsystem` + TTS) — «Вы туда чинить приехали или дом сносить?», «Кто закурил на газовой заявке?», «Сотрудник Серёга временно умер. Бывает.»

## 11. Аварии и катастрофа-комбо

**Новые аварии (связки готовых систем):**
- **Backdraft Boiler Relight** — котёл: пилот погас, газ копится; продуть ДО розжига, иначе фаербол. Очевидный фикс = ловушка.
- **Grounding the Flood** — 3-я опция к «свет↔ток»: заземляющий кабель (2 точки) → можно работать при свете, но кто-то держит кабель натянутым.
- **Sump Pump Race** — подвал заполняется (FluidFlux); уронить+запустить насос; завёл при живом щитке → КЗ + электрификация воды.
- **Frozen Pipe Thaw** — труба лопнула, но замёрзла; греешь → хлынет → секунды на сварку. Газ в комнате → розжиг подожжёт (ice→water→fire).
- **Sewage Backup Geyser** — забитый стояк под давлением; качать вантузом, но напарник закрывает cleanout-вентиль, иначе гейзер амбре+пены.
- **Pressure-Relief Water Heater** — бойлер перегрет; стравить relief-вентиль быстро → ошпарит близких, в красном → разрыв. Безопасное и опасное действие = тот же вентиль.
- **Grease/Oil Slick** — разлив: ragdoll, роняет тяжёлое, скользит в напарников как кегли; ещё и горюч.

**🔥 Катастрофа-комбо** (формализовать в DataTable: 4 катастрофы × действие × порядок): «газ+потоп» — нельзя варить (вода) и нельзя качать (мотор подожжёт газ). Новые связки = строками, не C++.

## 12. Туалет, амбре, запах, грязь, био

*(`AToilet`/`ABioProjectile`/`AFoamPatch`, `bSoiled`, `ThrowBio` — уже в коде)*

**Тон:** 80% работа+хоррор, 15% кооп-косяки, **5% туалетный угар**. Редко и ситуационно → смешно, не кринж.

- Справить нужду занимает время, делает уязвимым, может включать мини-игру. Провал = шум, паника, монстр получает сигнал. *(«Серёга, выходи!» — «Я НЕ МОГУ, У МЕНЯ МИНИ-ИГРА!»)*
- **Биологический снаряд** — редкий объект после санитарного инцидента: поднять в перчатках или статус «испачкан/воняет»; кинуть в тиммейта (экран пачкается, паника, монстр слышит) или в сторону (монстр уходит на запах).
- **Метановый детонатор** — амбре/`bSoiled` несёт метан: рядом огонь/сигарета/искра → «пфух», копоть, опаление. *(твоё облако подпаливает нагнувшегося помочь)*
- **Запах/грязь/следы** — от сигарет, газа, туалета, пота, горелой проводки, огнетушителя; некоторые монстры идут по запаху; грязный оставляет следы, хуже видит, отдельные строки в отчёте.

## 13. Отчёт после забега — мем-ядро

**Обязательно.** «Акт выполненных работ» превращает каждый забег в историю, которую друзья пересказывают.

Фиксировать: что починили/сломали, кто умер, кто курил при газе, кто кричал в рацию, кто спас огнетушителем, кто временно умер, **биологические инциденты** (кто не дошёл до туалета, кого выдал запах). Оператору — отдельная статистика (сколько предупредил/ошибся/смотрел в стену).

**Звания:** «Главный курильщик», «Паникёр смены», «Герой Газели», «Стажёр месяца», «Диверсант», «Спасатель», «Биологическое оружие смены», «Санитарная угроза», «Смотрел в стену».

**Финансы:** оплата за заявку, штрафы за ущерб/потерянные инструменты/компенсации. *Пример:* Оплата +18 000 ₽ / Сварочник −12 000 ₽ / Подъезд −80 000 ₽ / Жильцам −14 000 ₽ → **Итог: −88 000 ₽. «Работа выполнена. Премии не будет.»*

## 14. Экономика, прогрессия, репутация (DRG-глубина)

*(`CompanyLedgerSubsystem` + `FCareerStats` + `ReputationPoints` — уже в коде)*

- **Закрыл заявку — но в минус** из-за идиотских действий. Это норма и юмор.
- **Банк жадности (Hazard Pot)** — растёт от активной опасности (Leverage); зачисляется только при REPORT_OK у фургона, теряется при взрыве/вайпе. Безопасная игра платит меньше.
- **Доверие диспетчера** — `FCareerStats` помнит жадность/честность; влияет на будущие наряды и торг.
- **Репутация / звёзды жильцов** — жильцы ставят 1-5 (инциденты/амбре/время/воровство); средняя гейтит богатые vs трущобные наряды; самые смешные диспетчер читает вслух (TTS).
- **Износ инструмента + верстак** — `Wear`, может ОТКАЗАТЬ посреди сварки; чинить у фургона.
- **Апгрейды Hilux/гаража** — качать фургон (общий прогресс): больше кузов, зарядка, лебёдка для драга, крыша-прожектор, фаркоп под генератор.
- **Моды/оверклоки инструмента** *(DRG-слой)* — модификаторы поведения + рискованные оверклоки (больше пользы ценой нового риска).
- **Взятки/потерянные бумаги** — потратить баланс, чтобы стереть косяк/накрутить торг ×1.5.
- **Хабар и скупщик** — выносить ценности → сдать у фургона (режет выплату жильца и репутацию).
- **Престиж** — сезонный сброс ради статусной косметики/званий.

## 15. Движок реиграбельности (процедурность данными, не геометрией)

- **Seeded job-graph (симптом→корень)** — цепочка `ARepairable` от симптома вниз к причине (нет света ← залит щиток ← лопнула труба); глубина растёт с номером ночи. «Заявка ВРЁТ» — процедурно.
- **Эскалирующая смена с остаточным состоянием** — ночь = очередь 3-5 нарядов; недочинил → переносится худшим стартом. Улица деградирует за смену.
- **Колода мутаторов** — 2-3 тега на вызов: «старая проводка» (искра на починку), «зима» (потоп→лёд), «жилец дома», «ночь без луны», «счётчик мотает» (слив оплаты/сек).
- **Жилец как переменная хаоса** — дед-хозяйственник (рубильник обратно), бабушка (медленная эвакуация), пьяный (сигарета у газа), хомяк (хлам на пути).
- **Погода ночи** — гроза→электрика, похолодание→потоп/лёд, жара→газ/огонь.
- **Рулетка отсутствующего инструмента** — отнимает ключевой инструмент → колхоз-путь или доставка (деньги/время). Расширяет `bCheapGear`.
- **Живая доска приоритетов** (`ACallBoard`) — наряды 🔴/🟠/🟢 с таймерами гниения; проигнорил 🔴 → эскалация/пострадал жилец.
- **«Район» с памятью** *(длинный хвост DRG)* — компания работает очередь адресов; разрушенные дома (`BuildingsBlownUp` трекается) остаются и редиспатчатся с прошлым уроном. Прошлая криворукость = будущий контент.

## 19. Главные правила дизайна (+ DRG)

5. Игра рождает истории: «помнишь, как мы взорвали подъезд, но заявку закрыли?»
6. **🆕 Мерь каждую фичу реиграбельностью/ретеншном** (северная звезда DRG). Гэги — приправа, костяк — на возврат.
7. **🆕 Юмор редкий, но сильный.** Туалетный угар — 5%, не больше.

## 20. Финальная формула

«Аварийка» — не симулятор туалета и не чистый хоррор. Это **коопный аварийный хаос с DRG-глубиной**: друзья чинят объект, пугаются, спасают друг друга огнетушителем, руинят миссию своими ошибками, ржут над отчётом — и **возвращаются месяцами** за прокачкой, косметикой, Hazard-тирами и процедурным районом с памятью.

- Каждая механика → история **и** реиграбельность.
- Юмор редкий, но сильный.
- Монстр — угроза, друзья — источник хаоса.
- Самый ценный результат матча: не победа, а «помнишь, как мы тогда...» — и желание зайти ещё раз.

# 🔧 АВАРИЙКА

### Кооп-хоррор-комедия про аварийную бригаду, которая создаёт больше проблем, чем чинит

---

## В двух словах

Вы и ваши друзья — **аварийная ремонтная бригада**. Ночь, вызов, заброшенный объект: вырубило свет, травит газ, не работает генератор. Приезжаете на старом грузовике, берёте инструменты — и идёте чинить. План простой. Что может пойти не так?

Да всё. Свет потухнет в самый неподходящий момент, напарник запаникует и начнёт орать (а паника заразна), кто-то перепутает баллон с кофе и огнетушитель, кого-то так напугает темнота, что случится **санитарный инцидент**. А диспетчер по рации будет язвительно комментировать каждый ваш косяк и в конце выпишет «Акт выполненных работ» — с премией или штрафом.

Это игра про то, как **четыре взрослых мужика с инструментами устраивают хаос, пытаясь навести порядок.**

---

## Вайб

Если **Lethal Company** и **Phasmophobia** встретились бы в подвале старого ЖЭКа в три часа ночи — получилась бы Аварийка. Современный реализм, тёмный юмор, кооп-паника. Не «ужасы со скримерами», а **смешной стресс**: вы будете и визжать, и ржать, часто одновременно.

---

## Как играть

**1. Получаете заявку.** Диспетчер по рации: «Объектов — три, на дворе ночь, премия под вопросом. Работаем.»

**2. Чините.** Каждая поломка — это не «зажал кнопку», а цепочка этапов с мини-играми:
- **Генератор:** почини корпус руками → залей бензин из канистры (тяжёлый предмет, тащить вдвоём удобнее) → дёрни шнур стартера.
- **Газовая труба:** завари сваркой → закрути вентиль в ритм.
- **Электрощиток:** притащи кабель → вставь предохранители → настрой тестером.

Промахнулся в мини-игре — откат прогресса, замкнуло, рвануло. Запаниковал — руки трясутся, чинить тяжелее.

**3. Выживаете.** За вами следят четыре шкалы: **здоровье, паника, выносливость и... позыв в туалет.** Да, в туалет. Перетерпел — будет стыдно и пахуче.

**4. Уезжаете.** Все живы, всё (или почти всё) починено — грузимся в машину. Диспетчер подбивает «Акт»: кто молодец, кто спалил половину объекта, кому выписали звание **«Электрик Эдисон»** (получил током), **«Пожарный наоборот»** (устроил взрыв) или **«Кофеман смены»**.

## Чем цепляет

### 🤝 Кооп, в котором вы — главная угроза друг другу
- **Паника заразна** — рядом с орущим напарником начинаешь дёргаться сам.
- **Тяжёлое — вдвоём** — генератор и катушку кабеля реально тащить вместе.
- **«Кто дёрнул рубильник?!»** — один чинит щиток, другой по глупости его обесточивает.
- Один общий бюджет бригады — повод спорить: «копим на нормальный фонарь или каждому по батарейке?»

### 😱 Страх — это механика, а не декорация
- **Темнота пугает по-настоящему:** пока вырублено питание и ты без света — паника ползёт вверх. Включи фонарь, встань под прожектор или почини щиток — отпустит.
- **Шумомер:** чем громче работаете, тем... ну, скоро узнаете, кто придёт на шум. *(Слепой монстр-слухач — в разработке. Он не видит. Он слышит. Тише.)*

### 😂 Комедия из мелочей
- **Кофе из термоса** бодрит и успокаивает — но это диуретик, и теперь ты бежишь не от опасности, а в туалет.
- Поскользнулся на собственной пене из огнетушителя. Ударился головой об трубу. Метнул в напарника гаечный ключ от испуга.
- Диспетчер всё это видит и **всё припомнит**.

### 📈 Есть ради чего возвращаться
- **Магазин снаряжения:** заработал — проапгрейдил убогий мигающий фонарь до прожектора, медленный тестер — до автомата.
- **Квоты диспетчера:** сдай N рублей за N смен — иначе контора закрыта, и карьера с нуля. Давление как в Lethal Company.
- **Репутация:** работаете чисто — дают жирные заявки; спалили дом — только дешёвый трэш.

## ⭐ ТОП быстрых побед (low-cost, максимум переиспользования) — делать первыми

1. **Дом дышит** — директор скрипов: `SC_Creak` (5 вар) + 13 файлов `creak_struct` играют из точек ЗА/НАД игроком, частота растёт с паникой/таймером, изредка чуть качнуть пустую `ADoor` (петля скрипит). Бесконечный ужас без монстра. *(кооп: при разделении каждому скрипит рядом → «это ты наверху?» — «я в подвале…»)*
2. **Витал-саботаж починки** — телесные дебаффы портят мини-игру: икота (`HiccupInterval`) дёргает курсор, отдышка (`Winded`) расширяет дрожь, паника трясёт зону. Спешка тела ломает руки. *(кооп: напарник держит зону, пока бегаешь к биотуалету)*
3. **Vent-Then-Weld** — газ у трубы накапливается заново; один вентилирует/крутит вентиль, другой варит мини-игру вслепую. Искра до очистки = взрыв на всю комнату (`M_Death`). *(кооп: friendly-fire, сварщик слеп и верит «чисто!»)*
4. **Lockout двух рубильников** — сильный КЗ в воде гасится ТОЛЬКО удержанием главного + суб-щитка в разных комнатах одновременно. Отпустил рано — ток вернулся в воду посреди починки. *(кооп: счёт по рации «на три…»)*
5. **Газовый бред** — долгая экспозиция газа: гуще мухи, глухой звук+сердце, 1 стингер, силуэт `CitizenNPC` на кадр, закрытая дверь «кажется открытой». Чисто клиентский визуал, лечится маской. *(кооп: «там кто-то на кухне!» — «маску надень, идиот»)*
6. **Метановый детонатор** — амбре/санитарный-инцидент (`bSoiled`) несут метан: рядом огонь/сигарета (`IsSmoking`)/искра → «пфух», копоть-декаль, лёгкое опаление. *(кооп: твоё облако подпаливает нагнувшегося помочь)*
7. **Фонарь умирает** — разряд батареи + мерцание от паники; долго в темноте → паника сама растёт; сел — достаёшь запаску из слота вслепую. *(кооп: упавший роняет фонарь → реанимация полуслепая)*
8. **Кривая реанимация** — будишь пощёчиной/нашатырём (`EItemEffect::Ammonia` уже будит); не тем предметом бэкфайр: кофе в лицо → +паника, био в упор → встал и обделался. *(кооп: «зачем ты в меня био ткнул»)*
9. **Toss-and-catch инструмент** — Hold-починка пинит на месте → инструмент кидают/передают по цепочке от ящика в безопасной до запиненного у трубы. *(кооп: роли «якорь» и «бегун»)*
10. **CO и канарейка** — невидимый угарный газ (без тинта/мух), только туннельное зрение/замедление сердца; ищется пищащим детектором (слот), маска даёт лишь время. *(кооп: с детектором — «глаза» бригады, кричит «теплее/холоднее»)*

## 🔧 Механики (новые аварии / связки готовых)

- **Backdraft Boiler Relight** *(low)* — котёл: пилот погас, газ копится в камере; продуть (bleed-вентиль, ждать пока стихнет шипение) ДО розжига, иначе фаербол. Очевидный фикс = ловушка.
- **Grounding the Flood** *(med)* — 3-я опция к «свет↔ток»: заземляющий кабель (2 точки крепления) от прибора к трубе → ток стекает, можно работать при свете. Но кто-то держит кабель натянутым = выключен из дела.
- **Sump Pump Race** *(med)* — подвал заполняется (FluidFlux, видимый уровень), уронить+запустить насос; завёл при живом щитке → КЗ + электрификация воды (как генератор). Откачать до розеток.
- **Frozen Pipe Thaw** *(low)* — труба лопнула, но замёрзла; греешь горелкой → хлынет → секунды на сварку. Если в комнате газ — пламя розжига его подожжёт (ice→water→fire).
- **Sewage Backup Geyser** *(low)* — забитый стояк под давлением; качать вантузом (Hold), но линия под давлением пока напарник не закрыл cleanout-вентиль → иначе гейзер амбре+пены на всех.
- **Pressure-Relief Water Heater** *(med)* — бойлер перегрет (стрелка в красном, бьёт паром); стравить relief-вентиль, но быстро → ошпарит близких, в красном → разрыв. Безопасное и опасное действие = тот же вентиль.
- **Grease/Oil Slick** *(med)* — разлив (жир на кухне / трансформаторное масло у щитка): ragdoll, роняет тяжёлое, скользит в напарников как кегли; ещё и горюч (искра → пожар на полу).
- **CoopHold-этап починки** *(med)* — новый тип `ARepairable`: фикс требует ДВУХ тел (вентиль-колесо вдвоём, держать крышку щитка пока второй внутри, держать хомут пока варят). Прогресс идёт, только пока ОБА держат; отпустил → откат + брызги/искры.

## 🤝 Кооп-взаимодействие

- **Two-Carry Heavy Haul** *(med)* — тяжёлое (генератор/насос/полный баллон/ящик) тегается TWO_PERSON: соло — ползком со стаггером, вдвоём — быстро, но движутся жёсткой связкой («левее! другое лево!») по узкой лестнице.
- **One Mask, Four Lungs** *(low)* — одна маска на бригаду: передают по очереди; упал в облаке — спасатель тащит или «надышать» через маску до двери, рискуя своим воздухом.
- **Электрифицированная вода — цепь спасения** *(low)* — напарник упал в воде при живом щитке; вода бьёт током → спасатель тоже падает. Цепь: A гасит щиток (в темноту), B тащит тело, C бинтует на сухом. Порядок не тот = два трупа.
- **Synchronized Dual-Main Shutoff** *(low)* — газовый и электрический мейны в разных комнатах; закрыть ОБА в окно в пару секунд (счёт по рации), иначе комната «перезаряжается».
- **Stay-On-The-Line** *(med)* — один заперт на рации-торге (уязвим, push-to-talk), остальные тушат; рычаг растёт с активной опасностью → соблазн «пусть погорит для навара», а бригада орёт «да почини уже». Диспетчер слышит их панику.

## 😂 Юмор / слапстик

- **Заклинило рацию (хот-майк позора)** *(med)* — перегретая рация залипает в ON, транслирует диспетчеру всё (мат, «спереть телек») → штраф через леджер + комментарии. Глушить — стукнуть рацию.
- **Огнетушитель — реактивная тяга** *(med)* — `Extinguish`+`AFoamPatch` уже есть; добавить ОТДАЧУ: толкает назад, на мокром/своей пене — ragdoll-проезд; струя в напарника = пол-экрана пены + откид.
- **Цепной завал** *(med)* — поскользнулся с холодильником → роняешь, предмет катится, сбивает напарников, может щёлкнуть рубильник/повалить прожектор. Домино.
- **Акт выполненных работ** *(med)* — перед выплатой диспетчер требует заполнить планшет (мини-игра курсор, шаблон `AToilet`) посреди дымящегося дома; абсурдные поля; промах → урезка выплаты.
- **Жилец-вредитель** *(high)* — хозяин (`CitizenNPC`) «помогает»: включает рубильник обратно, распахивает закрытые двери, хватает за рукав, паникует (`FearContagion`). *(нужен BT/навмеш — ai.* выключена)*
- **Жадность: вынос телевизора** *(med)* — ценности как Heavy-предметы: донёс до выхода → бонус; но руки заняты (нет инструмента/не поднять раненого), тормозит, спалили по рации/жильцом → штраф больше навара.

## 👻 Хоррор / атмосфера (без монстра)

- **Просадка щитка / brown-outs** *(med)* — живой щиток КОПИТ нагрузку (каждая авария/лампа), гул растёт по питчу, лампы дребезжат, за порогом — дуга + случайный 2-4с провал в темноту. Свет, которому нельзя доверять.
- **Подвал — врата страха** *(med)* — заход на лестницу: смена room-tone на Boiler_Room, капель громче, дверь захлопывается за бригадой (метал-слэм); единственный свет подвала — на щитке наверху.
- **Авария растёт сенсорно** *(high)* — газ сочится под двери (гуще `NS_Smoke`+шипение+мухи), вода поднимается по этажам (FluidFlux), огонь ползёт по `NS_Fire_Wall`; две аварии встретились → каскад во взрыв/электродом.
- **Связь рвётся** *(med)* — диспетчер — единственный человеческий голос; сигнал глохнет в подвале/в грозу/при панике; реплики смешные, но с дурным предчувствием.
- **Гроза рулит светом** *(med)* — гром бьёт вспышкой в окна (бесплатный кино-свет), близкий разряд может ВЫБИТЬ щиток (внезапная темнота); вспышка силуэтит вешалку/`CitizenNPC` на кадр.
- **Прошлая бригада** *(low)* — статичный сторителлинг: брошенный чужой ящик, мерцающий упавший фонарь, записки-декали («НЕ ВКЛЮЧАТЬ ЩИТОК»), стул подпёр дверь подвала, неподвижный хозяин в кресле. Ничего не двигается — и потому жутко.

## 💰 Прогрессия / экономика (поверх рации-торга + леджера)

- **Доверие диспетчера** *(med)* — `FCareerStats` помнит: жадность портит будущие наряды, честность платит лучше; влияет на исход торга через смены.
- **Банк жадности (Hazard Pot)** *(med)* — пот растёт от Leverage; зачисляется в ShiftNet только при REPORT_OK у фургона, теряется если дом взорвался/вайп. Безопасная игра платит меньше.
- **Взятки / потерянные бумаги** *(low)* — потратить баланс, чтобы стереть косяк/пролезть без очереди/накрутить торг ×1.5; диспетчер может «положить в карман».
- **Хабар и скупщик** *(med)* — выносить ценности → сдать у фургона; занимает слоты, режет выплату жильца и репутацию.
- **Износ инструмента + верстак** *(med)* — у инструмента Wear, может ОТКАЗАТЬ посреди сварки пока копится газ; чинить у фургона.
- **Апгрейды Hilux/гаража** *(med)* — качать фургон, не инструмент: больше кузов, бесплатная зарядка, лебёдка для драга, крыша-прожектор, фаркоп под генератор. Общий прогресс.
- **Звёзды от жильцов** *(med)* — жильцы ставят 1-5 (инциденты/амбре/время/воровство); средняя гейтит богатые vs трущобные наряды; самые смешные диспетчер читает вслух (TTS).

## 🔁 Реиграбельность / процедурность (вариативность данными, не геометрией)

- **Seeded job-graph (симптом→корень)** *(med)* — генератор цепочки `ARepairable` от симптома вниз к причине (нет света ← залит щиток ← лопнула труба); глубина растёт с номером ночи. «Заявка ВРЁТ» становится процедурной.
- **Эскалирующая смена с остаточным состоянием** *(med)* — ночь = очередь 3-5 нарядов; недочинил (полупотоп, открытый вентиль) → переносится в следующий вызов худшим стартом. Улица деградирует за смену.
- **Колода мутаторов** *(low)* — 2-3 тега на вызов: «старая проводка» (искра на починку), «зима» (потоп замерзает в лёд-скольжение), «жилец дома», «ночь без луны» (тьма, только фонарь), «счётчик мотает» (слив оплаты/сек). Дом играется иначе.
- **Жилец как переменная хаоса** *(med)* — тип жильца роллится: дед-хозяйственник (рубильник обратно), бабушка (медленная эвакуация), пьяный (сигарета у газа), хомяк (хлам на пути).
- **Погода ночи** *(low)* — глобальный тон смены: гроза → электрика (молния реэнерджит щиток), похолодание → потоп/лёд, жара → газ/огонь.
- **Рулетка отсутствующего инструмента** *(low)* — генератор отнимает ключевой инструмент → колхоз-путь (есть) или вызов доставки (деньги/время). Расширяет `bCheapGear` с шмота на инструмент.
- **Живая доска приоритетов** *(med)* — `ACallBoard` стримит наряды 🔴/🟠/🟢 с таймерами гниения; проигнорил 🔴 → эскалация (утечка→взрыв) или пострадал жилец (−репутация).
- **Таблица катастроф-комбо** *(med)* — формализовать 4 катастрофы × действие × порядок в DataTable → новые связки строками, не C++ («газ+потоп»: нельзя варить — вода, нельзя качать — мотор подожжёт газ).
- **«Район» с памятью** *(high)* — компания работает очередь адресов; разрушенные дома (`BuildingsBlownUp` уже трекается) остаются и реди­спатчатся с прошлым уроном. Прошлая криворукость = будущий контент.

# «Аварийка» — Банк идей

Отсортировано: 🟢 дёшево + сильно ложится на концепт · 🟡 средне · 🔴 дорого/на потом.
Помечено ⚡ если опирается на УЖЕ готовый код (почти бесплатно).

---

## 🟢 ЭКОНОМИКА И ПРОГРЕССИЯ

**⚡ Магазин снаряжения** (обсудили) — общий бюджет бригады, апгрейды плохой→хороший инструмент, в ГАЗели/планшете. Опирается на готовый «Акт» с рублями.

**⚡ Заявки разной сложности и оплаты** — дешёвые-безопасные (жилой дом) → дорогие-смертельные (корабль). Выбор заявки на карте/планшете. Прогрессия + причина возвращаться.

**Квоты как в Lethal Company** — диспетчер требует «сдать N рублей за 3 смены, иначе увольнение». Создаёт давление и цель. Провалил квоту → game over, начинай карьеру заново. Это главный крючок Lethal Company.

**Репутация бригады** — чем чище работаете, тем лучше заявки/оплата. Накосячили (взорвали дом) → дают только дешёвый трэш. Связано с «Актом».

**Страховка инструмента** — платишь страховку, потерял сварочник в забеге → вернут (частично). Кооп-решение «стоит ли страховать дорогое».

**💡 Чёрный список объектов** — на особо проклятых заявках платят х3, но шанс не вернуться огромен. «Пацаны, идём на маяк? Там платят бешено, но оттуда никто не возвращался».

---

## 🟢 МОНСТР И СТРАХ (опираются на готовый шум/запах/панику)

**⚡ Голосовой чат кормит монстра** — слухач реагирует на реальный голос в микрофон. Орёшь от страха → он идёт. Гениально ложится на концепт (Lethal Company так делает).

**⚡ Запаховый след** (есть в концепте!) — монстр идёт по запаху (сигареты, газ, санинцидент, пот паники). Недооценённая механика, у тебя уже есть система запаха.

**⚡ Монстр учится на шуме** — чем больше шумишь за забег, тем агрессивнее он становится к концу. Наказывает за весь забег, не только за момент.

**Ложные звуки** — монстр иногда имитирует знакомые звуки (капля, скрип, шаги «своего»), чтобы заманить. Дёшево (это просто проигрывание звука из точки).

**💡 Монстр боится света-прожектора** — поставил стационарный прожектор → зона безопасна, но прожектор шумит (генератор) и его видно. Связь твоих механик: свет=безопасность, но свет=шум=приманка. Дилемма.

**💡 «Он в стенах»** — монстр перемещается по вентиляции/стенам, слышен стук труб, появляется из неожиданных мест. Усиливает паранойю в техническом сеттинге (у тебя везде трубы).

**Несколько монстров на сложных заявках** — на дорогих картах не один слухач, а слухач+подражатель вместе. Хаос.

---

## 🟢 КООП-ХАОС (твой главный жанр)

**⚡ Предохранитель не туда** — электрик вставил предохранитель в неправильный сектор → вырубил свет там, где работает напарник. Уже есть перегрузка сети в коде, расширить.

**⚡ «Кто включил рубильник?!»** — один чинит щиток, другой случайно дёрнул рубильник → удар током первому. Кооп-косяк, опирается на готовую электрику.

**Общий ключ один на всех** — нужный ключ один, передавать из рук в руки. Потерял в темноте → вся бригада ищет. Создаёт зависимость друг от друга.

**Тяжёлое вдвоём** — генератор/катушку реально тащить ВДВОЁМ (один не утащит или очень медленно). Заставляет кооперироваться физически.

**💡 Рация — единственная связь** — разошлись по этажам, видите друг друга только через рацию и камеры оператора. Оператор координирует «Серёга налево, там монстр». Усиливает роль оператора.

**💡 Предатель-режим (опционально)** — раз в N игр один игрок тайно «диверсант» (по сюжету — конкурент-саботажник). Among Us внутри аварийки. Очень рискованно для баланса, но дико смешно. На потом.

**Голосование «уезжаем?»** — когда хаос, любой может запустить голосование на эвакуацию. Бросить раненого ради спасения остальных = драма.

---

## 🟢 КОМЕДИЯ (твоя фишка, дёшево)

**⚡ Расширить звания в «Акте»** — больше мемных титулов: «Электрик Эдисон» (получил ток 5 раз), «Пожарный наоборот» (устроил пожар), «Тихушник» (ни разу не шумел), «Камикадзе» (взорвал себя). Чистый текст, копейки.

**Диспетчер запоминает** — реплики ссылаются на прошлые смены: «Опять ты, Серёга? В прошлый раз дом спалил». Нужен SaveGame истории.

**⚡ Санинцидент — последствия** — провонявший игрок: NPC-диспетчер комментирует, тиммейты отходят, монстр идёт на запах. Уже есть статус «воняет», добить реакции.

**Пасхалки на объектах** — записки, смешные надписи на стенах, абсурдные предметы (резиновая утка в больнице). Дёшево, игроки любят находить.

**💡 «Производственная травма»** — абсурдные мелкие неудачи: поскользнулся на своей же пене, защемило палец дверью, ударился об трубу головой. Микро-юмор физкомедии.

**Кастомизация каски/жилета** — наклейки, цвета, надписи на спине («СТАЖЁР», «НЕ ТРОГАЙ»). Идентичность + повод гриндить.

---

## 🟡 ГЕЙМПЛЕЙНЫЕ СИСТЕМЫ

**Погода влияет на заявку** — гроза (молнии бьют по щитку, доп. аварии), туман (хуже видно), дождь (скользко, заливает электрику). Разнообразит забеги.

**Время суток / смены** — ночная смена (темно, страшно, платят больше) vs дневная (видно, безопасно, платят мало). Выбор риск/награда.

**Деградация объекта** — чем дольше тянешь с починкой, тем хуже: газ накапливается, вода прибывает, пожар разрастается. Давление времени (часть есть — газ растёт).

**Случайные события** — посреди забега: отключение резервного питания, прорыв трубы, «звонок жильца» (доп. задача). Не даёт заучить карту.

**💡 Динамические поломки-цепочки** — починил щиток → перегруз → выбило в другом месте → там загорелось → нужен огнетушитель. Аварии порождают аварии. Очень в духе «команда сама создаёт проблемы».

**Расходники с весом** — нельзя унести всё, выбираешь что брать из багажника. Кооп-распределение «ты бери аптечки, я батарейки».

---

## 🟡 ЛОКАЦИИ (контент после флагмана)

**Процедурная расстановка** — поломки/лут/монстр спавнятся в разных местах каждый забег. Реиграбельность на одной карте (есть для поломок).

**Модификаторы заявки** — «без света вообще», «двойной газ», «монстр агрессивный», «нет рации». За сложные модификаторы — х2 оплата.

**💡 Вертикальность** — многоэтажки, где монстр между этажами, лифт (сломанный/работающий как ловушка), лестницы как хоум境. У тебя больница многоэтажная.

**Секретные зоны** — за доп. усилия (вскрыть ломом, найти ключ) — комната с ценным лутом/лором. Награда за исследование.

---

## 🟡 СОЦИАЛЬНОЕ / РЕТЕНШН

**⚡ Шаринг «Акта»** — кнопка «поделиться отчётом» (красивая картинка с званиями). Вирусный маркетинг (как смерти в Lethal Company скриншотят).

**Реплеи/킬-кам** — запись эпичных моментов (взрыв, смерть) для шаринга. Дорого, но мощно для маркетинга.

**Статистика карьеры** — сколько смен, рублей, смертей, выкуренных сигарет за всё время. Игроки любят цифры.

**Достижения Steam** — «Покури 100 сигарет», «Выживи без единого шума», «Взорви 10 домов». Ретеншн + смешные.

**Сезонный контент** — Хэллоуин (монстр в костюме), Новый год (объект — ёлка коротит). Поводы вернуться.

---

## 🔴 НА ДАЛЁКОЕ ПОТОМ (дорого)

**Кастомные монстры/объекты от комьюнити** (моддинг) — огромный ретеншн, но сложно.

**Кросс-платформа** (консоли) — расширяет аудиторию, дорого сертифицировать.

**Сюжетная кампания** — нарратив про бригаду, боссы. Меняет жанр, много работы.

**ИИ-напарники для соло** — боты-монтёры если играешь один. Сложный ИИ.

## ТОП-10 ЧТО Я БЫ ДЕЛАЛ В ПЕРВУЮ ОЧЕРЕДЬ

Опираясь на «дёшево + сильно ложится + есть код»:

1. ⚡ **Магазин + общий бюджет** (экономика готова) — даёт цель
2. ⚡ **Квоты диспетчера** (давление + game over) — крючок Lethal Company
3. ⚡ **Голос в микрофон кормит монстра** — идеально для концепта
4. ⚡ **Запаховый след** (уже в концепте + код запаха есть)
5. ⚡ **Заявки разной сложности/оплаты** — прогрессия
6. ⚡ **Больше мемных званий + шаринг «Акта»** — вирусность, копейки
7. ⚡ **Динамические цепочки поломок** — твой главный вайб «команда создаёт хаос»
8. **Тяжёлое вдвоём** — заставляет кооперироваться
9. **Модификаторы заявок** (х2 оплата за хардкор) — реиграбельность
10. **Достижения Steam** — ретеншн + юмор

## ПРИНЦИП ПРИОРИТИЗАЦИИ

Не делай всё. Спрашивай по каждой идее:
1. **Создаёт ли это КООП-ситуацию?** (твой главный принцип) — да → приоритет
2. **Опирается на готовый код?** — да → дёшево, делай
3. **Это core или polish?** — core (магазин, монстр) раньше, polish (наклейки) позже
4. **Это для прототипа или для релиза?** — прототип проверяет фан, релизное наполнение потом

Лучшие идеи — те, что ⚡ (есть код) + 🟢 (ложатся на концепт). Их и бери первыми.

# PLAYER_APPEAL_PLAN — почему в игру будут играть и любить

> 2026-06-22. Анализ 4 линз (хук/первый час · ретеншн/DRG · кооп-социалка/виральность · хоррор-комедия айдентика) → 46 идей → синтез.
> Север: [[north-star-drg]] (масштаб Deep Rock Galactic). Тон: страшно+смешно, дом=враг.

## Вердикт
Строить аппил на уникальном хуке **«бытовая авария = монстр, дом — антагонист»**, обёрнутом в **живой циничный голос диспетчера** и **emergent-хаос, который сам нарезает клипы**. Фундамент УЖЕ готов — его надо **подсветить и связать**, а не добавлять бестиарий. Ближний горизонт: не новые системы, а петля «ещё заход» + авто-истории из готового.

## TOP NOW — делать скоро (высокий эффект / низкая цена, на готовом)
1. **Диспетчер-персонаж: event-driven озвучка/реакции.** Реплики на триггеры (взрыв/ток/биоснаряд/смерть/лут) = «игра знает про ваш хаос». Это онбординг (понятно за 30 сек, без туториала) + тон + мемы в одном. _Есть: диспетчер в коде, все хазарды шлют события, SPEC_Radio_Haggle/SOUND_MAP заготовлены → нужен пул строк по событиям + субтитры._
2. **Доска позора / Сводка ЧП в конце смены.** Кристаллизует забег в историю с виноватыми («Поджигатель», «Титаник», «Балласт»). Соц-клей + скриншот-топливо + пинок «отыграться». _Есть: все счётчики трекаются → нужен агрегирующий экран итогов (у нас уже есть «Акт» — расширить)._
3. **Растущая квота конторы + касса видна на ГАЗели.** Табло «Касса: N ₽» на борту + «+N» на каждый вынос → починка = «заработали НАМ на апгрейд» + драма «тащить или бежать». Петля «ещё заход». _Есть: касса, лут→вынос→продажа, магазин, репутация → нужны цель/дедлайн + диегетик-дисплей на ГАЗели._
4. **Hazard-тиры 1–5 (множители готовых систем).** Базовый рычаг ретеншна DRG: те же системы → сотни часов, игрок сам выбирает напряжение. Ноль нового контента. _Есть: скорость газа/число аварий/таймер/дешёвый комплект в C++ → множители в DataTable + выбор в UI._
5. **Доска заявок + мутаторы** («Темно»/«Утечка»/«Аврал»/«Премиум-клиент»). Выбор 3–4 заявок с ярлыками = разговор в дискорде + реиграбельность из комбинаторики. _Есть: диспетчер/репутация/статусы/дешёвый комплект → мутатор = флаг на старте + UI-хаб._
6. **Газель-экстракция под давлением + дилемма «раненый ИЛИ лут».** Пиковый клипируемый момент (DRG drop-pod, Lethal door): гудок, обратный таймер, перегруз, «оставили Колю». _Есть: экстракция, вынос лута, bleed-out, «1 тяжёлый» → раненого сделать «тяжёлым» слотом + таймер/гудок/решение уехать._
7. **Голосовые барки + статусы видны на ДРУГИХ.** Усиливает диегетику HUD: слышишь себя (мат от тока, кашель от вони), читаешь напарника со стороны (мухи/капли/тряска) → дебаффы = кооп-шутки без UI. Сочная юмор-смерть с дропом лута. _Есть: статусы и HUD-диегетика на тех же событиях; физика/инвентарь дают дроп._

## BIG BETS — крупные ставки под DRG-север
1. **Каскады аварий** (слой «событие A → B»): лужа дотекла до щитка→ток в воде; газ нашёл искру→взрыв→спринклер→потоп под током. Главный emergent-движок, бесконечная реиграбельность без нового контента. _Хазарды есть → нужен слой таймеров эскалации + связи комната↔комната._
2. **Оверклоки инструментов + мягкие роли через них.** Не «+10%», а смена стиля с трейд-оффами (сварочник: быстрый шов, но поджигает газ) → споры о билдах + кооп-зависимость «кто со сваркой?!» без жёстких классов. Сердце 50–200ч.
3. **Лицензия конторы = мета-спайн + престиж.** Репутация→уровни лицензии (Бытовая→Промышленная→Медицинская) органично гейтят 3 карты по ТЗ (Дом→Завод→Больница) + Hazard-тиры + слоты апгрейдов; «перелицензирование» = престиж. Длинная ось «к чему иду».
4. **Процедурный seeded-спавн аварий + «Авария недели» (лидерборд).** Ручной RE7-дом выгорает за 3–4 захода; seed-раскладка оживляет на сотни часов + календарный крючок «зайти в четверг, позвать команду». Самый высокий effort, но ключ к долгому ретеншну.
5. **Нагрудные камеры → авто-клип/реплей + проксимити-голос с рацией.** ДНК Content Warning + виральность Lethal: камеры УЖЕ есть → повтор смертей с камеры товарища, «сохранить 15 сек»; позиционный голос + помехи рации = «ты где?!», разделение группы. Роль оператора для 4-го/мёртвого.

## AVOID — чего НЕ делать
- ❌ **Монстр-слухач/бестиарий** — размывает айдентику «дом=враг», и без отмашки. Страх держать фейк-скримерами + хазардами (шумовая база = задел).
- ❌ **Жёсткие классы с локами** — только мягкие роли через инструменты/оверклоки (каждый может всё, связка эффективнее) → низкий порог входа.
- ❌ **Косметика/престиж/монетизация и ручные «комнаты-истории»** — пока не стоит кор-петля (квота+каскады+тиры+seeded). Иначе ручной контент сгорит за 3–4 захода.
- ❌ **Полоски/цифровой HUD и фиолетовый в UI** — держать диегетику (сердцебиение/виньетка/барки), акцент оранжевый.
- ❌ **Кулдауны/гейты на физкомедию** (толчок/биоснаряд) и **отдельный текст-туториал** — бесплатный хаос + голос диспетчера и есть онбординг и вирусность.

## Порядок (рекоменд.)
Сначала **TOP NOW 1–3** (диспетчер-реакции + сводка ЧП + квота/касса) — дёшево, сразу даёт «ещё заход» и тон. Потом **тиры+доска заявок+экстракция-дилемма**. Параллельно фундамент под **big bet «каскады»** (он множит всё). Косметику/seeded/оверклоки — когда кор-петля стоит.

# «Авариика» — бриф проекта (для составления плана)

> Документ самодостаточный: всё нужное здесь, доступа к репозиторию у тебя нет.
> Нужно: помочь составить план дальнейшей разработки 1-го этажа дома и игрового цикла.

## 1. Что за игра
Кооперативный **хоррор-комедия** про бригаду аварийной службы (сантехника/электрика/газ).
Игроки приезжают по заявке в дом, **устраняют аварии** (прорыв воды, утечка газа, обрыв
проводки, неисправные двери), борются со **шкалой паники** и бытовыми «угрозами», получают
оплату и уезжают. Тон: серьёзная авария + бытовой абсурд. Кооп до 4 игроков.

Базовый игровой цикл (готов и PIE-проверен): **заявка (доска в хабе) → приехать → починить
аварии (вода/газ/электрика/двери) → выход (ExitZone) → оплата**. Есть шкалы здоровья, паники,
«туалета», система перетаскивания (drag) сбитого напарника, рация.

## 2. Технологии
- **Unreal Engine 5.7.4**, рендер Lumen, апскейл TSR (база).
- Игровой **C++ модуль `Avaryo`** (основная логика на C++, контент/настройка — в Blueprint поверх).
- Сетевой кооп: OnlineSubsystem (сейчас **Null** для локальных тестов) + плагин **EOSCore** (Epic Online Services) для будущего онлайна. Ключи EOS в `DefaultEngine.ini`.
- Целевое железо разработчика: ~8 ГБ VRAM сейчас (план апгрейда на RTX 4080S/5080) — перф держать умеренным.
- Платформа разработки: Windows 11, редактор UE открыт; правки C++ — Live Coding (тело функций) или Build.bat (новые члены/полная пересборка).

## 3. C++ классы (Source/Avaryo)
**Персонаж/компоненты:**
- `AAvaryoCharacter` — игрок, true-FPS шаблон UE5.4 (FP-камера на кости head). Здоровье/урон, инвентарь, взаимодействие (E), фонарик, drag напарника, монтажи реакций (сейчас ОТКЛЮЧЕНЫ для чистой локомоции).
- `UVitalsComponent` — здоровье, паника, «туалет»; события OnWounded/OnRevived. (Сейчас Health/Panic = 50/50 для тестов; **перед релизом вернуть 100/0**.)
- `UFlashlightComponent` — фонарик.

**Мир / интерактив:**
- `ARepairable` — база аварий. Подтипы по данным: `Repairable_WaterPipe` (💧 прорыв воды), `Repairable_GasPipe` (🔥 утечка газа). Чинится инструментом.
- `APowerSwitch` — рубильник/электрощит; `bLiveWireWhenBroken` (живой провод бьёт током при разливе воды).
- `ADoor` — дверь (открытие E), может быть заперта/сломана.
- `AExitZone` — зона выхода (завершение заявки).
- `ACallBoard` — доска заявок в хабе (выбор задания «Дом» → грузит карту `L_Dom`).
- `AToilet`, `AFoamPatch` (пена/разлив), `AFloodlight`, `AToolCase` (ящик инструментов), `ATrap`.
- `ABioPickup`/`ABioProjectile`/`APickupItem` — предметы/пикапы. Инвентарь: «1 тяжёлый предмет на земле + 4 слота».

**Game/UI:**
- `ARunState` — состояние забега (заявка, прогресс, оплата).
- `AvaryoPlayerController`, `MenuGameMode`/`MenuHUD`, `AvaryoHUD`, `DispatchSubsystem` (диспетчер заявок), `CompanyLedgerSubsystem` (бухгалтерия/деньги), `AvariikaOnlineSubsystem`, `AvariikaSaveGame`, `AvaryoCameraShakes`.

## 7. Жёсткие правила (НЕ нарушать)
- Монстра-слухача НЕ делать без явной отмашки пользователя.
- Перед релизом вернуть Health=100, Panic=0 (сейчас 50/50 для тестов).
- Фиолетовый цвет в UI запрещён, акцент — **оранжевый**.
- Паки = плейсхолдеры, до релиза заменить/лицензировать; не «обходить» сменой модели.
- Работа по модулям: один модуль до конца (код+сборка+смоук+размещение+доки+пуш), потом следующий.
- Сборка/правки уровня — при определённом состоянии редактора (есть свои нюансы инструментов).
